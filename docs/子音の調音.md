# 子音の調音

子音がおかしいとき，どこを見て，何を直すか．数値と経緯は [experiments/consonant-articulation](../experiments/consonant-articulation/README.md) にある．

## 診断基準

子音は短く，静かな部分も含むので，平均のスペクトルでは分からない．**一つの子音を時間で区切り，区間ごとに見る所を変える**．

| 区間 | 見る所 | 分かること |
|---|---|---|
| 閉鎖（音の止まる所） | 長さ（ms） | 短いと「っ」のない弱い子音，長すぎると詰まる |
| | 80–500 Hz の強さ（母音との差） | 声の有無．有声なら母音の −5〜−15 dB で続く．無声なら消える |
| | 1–8 kHz の強さ | 閉じ具合．息がどこかから漏れていれば下がりきらない |
| 破裂（離す瞬間） | 1–2，2–4，4–8 kHz それぞれの強さ | 弾ける音の強さと，調音位置（p 低い，k 中，t 高い） |
| 離し〜母音 | 破裂から声までの時間（VOT） | 無声 20–30 ms，有声 0–10 ms |
| | 母音の頭の HNR（声の周期成分と雑音の比） | 低ければ気息が残る（有声有気音に聞こえる） |
| 摩擦 | 重心（kHz） | 狭めの位置と広さ．浅い狭めは重心が下がる |
| | 1 kHz ごとの強さ | 重心だけでは同じでも形が違うことがある．s ɕ は 6 kHz 以上が主役で，3–5 kHz が勝つと濁る |
| | 80–500 Hz の強さ | 声の漏れ（無声）と声の弱さ（有声） |
| | 次の母音との強さの差 | 摩擦全体の大きさ |
| | 5 kHz 以上の雑音と 1 kHz 以下の声の差 | 有声摩擦の効き．雑音が足りていても，声が強いと埋もれて弱く聞こえる |
| 弾き（ら行） | 1–8 kHz の落ち込みの深さ | −20 dB 台なら「ら」，−40 dB 以下は「だ」 |
| | 前後の F2 の動き | 人はどの母音でも 2000 Hz 付近へ寄る．下がると巻き舌・[l] のような癖になる |
| | 抜ける速さ | 人は離して 10 ms で元に戻る．遅いと [l] 寄り |
| 鼻音 | 1–3 kHz の強さ | 口蓋帆の開き具合．低ければこもる |
| 全体 | 子音長 | 短いと他のすべてが悪くなる．**最初に見る** |

**良し悪しは目標の値でなく，人の散らばりで決める**．JVS の女性 51 人が同じ文を読んだ同じ子音を測り，中央値から散らばりの何倍離れているか（z）を出す．2 を超えたら疑う．1 以下は個人差なので直さない．

音だけでは原因が決まらないので，合成器の中も見る．人の録音にはない強みである．

- 最も狭い所の断面積（cm²）と，その位置：狭めに届いているか，別の所（前歯など）が狭くないか
- 口腔内圧（肺圧に対する %）：75 % を超えると声帯が止まる
- 声門の開きと流量：離したあともまだ開いていれば気息になる

気をつけること：

- 人の無声閉鎖が静かでないのは収録の背景雑音による．合成のほうが静かでも失敗ではない．
- 短い区間ほど窓が隣の音を拾う．早口の「声の漏れ」の一部は測り方による．

## 「規則」とは

音を作るまでに，二つの別のものが働く．

| | 何を決めるか | どこにあるか |
|---|---|---|
| **話者（形状）** | 子音ごとの，口の形と声門の形の**目標** | `speakers/…/*.speaker` |
| **規則** | その目標へ**いつ，どれだけの速さで，どれだけの間**向かうか | 下の二か所 |

規則は二段になっている．

1. `experiments/japanese-accent/accent.py`：かなを区間（子音の名前と長さ）の列にする．子音長，「じ」を [dʑ] と [ʑ] のどちらにするか，口蓋帆の開きなど．
2. `backend/GesturalScore.cpp`：区間の列を**ジェスチャ**（どの形状へ，いつからいつまで，どの時定数で）に直す．閉鎖の始めと終わり，声門を開閉する時刻，VOT，離しの速さなど．

「規則の修正」はこの二つを直すこと，つまり**形は同じまま時間の取り方を変えること**を指す．2 はもともと英語・ドイツ語の話者に合わせてあるので，区間に `timing = ja` と書かれたときだけ日本語の値を使う．書かれていない区間の結果は変わらない．

VTL の調音は目標へすぐには着かない．時定数 τ のとき，着くまでおよそ 10 τ かかる．τ = 10 ms なら 100 ms である．閉鎖の時刻だけは，規則が逆算して合わせている．

## 修正の仕方

1. **長さ**を人に合わせる（`accent.py`）．
2. **目標の形**を見る．止まった状態で，狭めの面積・位置・他に狭い所がないかを確かめる．悪ければ話者を直す．
3. **目標に着いているか**を見る．着いていなければ規則（始める時刻，τ）を直す．
4. **声門との時刻のずれ**を見る．口の形が合っていて声や息がおかしければ，声門の形か時刻．
5. 測り直して z を見る．ほかの測度が悪くなっていないかも見る．最後は耳で決める．

| 聞こえ方 | 見る所 | よくある原因 | 直す所 |
|---|---|---|---|
| 破裂が弱い（k t） | 破裂の帯域 | 前歯の隙間が狭く破裂をふさぐ | 形状（顎と唇を開く） |
| | 閉鎖長 | 子音が短い | 規則（長さ） |
| | | 声門が離す前に閉じている | 規則（声門の時刻） |
| 濁音が清音に聞こえる | 閉鎖中の 80–500 Hz | 口腔内圧が上がり声帯が止まる | 声門の形（閉じる），規則（早く閉じる，閉鎖を短く，わずかに鼻へ逃がす） |
| 濁音の前後の母音が張る | 母音の頭と末尾のピーク（発話の平均に対して） | 閉鎖のために閉じた声門が，漏れの多いモーダルより大きく鳴る | 声門の形（振動の振幅を下げる） |
| t が強い | t だけの 2–8 kHz（k と混ぜない） | 離しの後の気息が強い | 規則（声門を早く閉じ始める） |
| 濁音に息が混じる | 母音の頭の HNR | 声門が離しのあとも開いている | 声門の形（開きすぎない），規則（早く戻す） |
| 濁った摩擦が弱い（ざ行） | 雑音と声の差 | 声門の開きが足りず，声が強く雑音が弱い | 声門の形（開く），規則（その分早く戻す） |
| s が「しゃ」っぽい，こもる | 重心，6 kHz 以上 | 狭めが浅い，前歯がふさぐ | 形状 |
| 「し」が「ち」になる | 面積 | 狭めが閉じきる | 形状 |
| 「ら」が「だ」に聞こえる | 落ち込みの深さ | 完全に閉じている | 形状（舌の横を開ける），規則（閉じたとみなす面積） |
| ら行に癖がある | F2 の動き | 舌先だけ動き，舌本体が母音のまま | 形状（舌本体を前へ） |
| 早口でぼやける | 目標への到達率 | τ と移行の時間が固定 | 規則（短い区間ほど τ を短く） |

### 2026-11 に直したもの（v1.1.2）

- **閉鎖中の声**：声門が閉じ終わる前に口を閉じるので，口腔内圧がすぐ 50–90 % になり声が止まっていた．閉鎖の 70 ms 前から速く閉じ，閉鎖を人の長さ（約 50 → 30 ms）に縮め，口蓋帆を 0.02–0.04 cm² だけ開けた．が行は人も閉じきらないことが多いので，[ɣ] 寄りにした．
- **有声摩擦（ざ行・じゃ行）**：有声有気音になっていた（v1.1.3 で直し方を改めた）．声門が [h] のように開き，離しのあと約 40 ms 開いたままだった（HNR 8–14 dB，人は 17–19）．開きを減らし，早く戻すようにして 16–17 dB．有声破裂のほうは，離しのあとに気息はない．
- **ら行**：約 9 ms 完全に閉じ，落ち込みは −45 dB（人は −23）だった．舌の高さでは加減できない（動きの 2 % で 0 から 0.15 cm² に飛ぶ）ので，舌の横に 0.1 cm² の隙間を作り，閉じきらないようにして −23 dB．
- **早口**：実際に到達していなかった．短い区間では τ を短くした．口の形の到達率は次のとおり．

| 2 倍速（1 秒に約 15 モーラ） | 前 | 後 |
|---|---|---|
| s，z | 0.86，0.80 | 0.98，0.99 |
| じゃ行 | 0.85 | 0.91 |
| k t | 0.77 | 0.81 |
| 口蓋帆（鼻音） | 0.50 | 0.90 |
| 声門（k t） | 0.43 | 0.69 |
| 声門（摩擦，b d g） | 0.76–0.83 | 0.98–1.00 |

閉鎖とら行の接触は，速くしても必ず届く（ただし短くなる）．ふは 1.75 倍以上で [f] になっていたので直した．ざ行は早口ほど声門を早く動かさないと雑音が消えたので，ふつうの速さと同じだけ先に動かす．**母音はまだ届かない**（F1・F2 が 0.5 Bark 以上ずれるものが 2 倍速で半分）．人も早口では母音が縮むので，そのままにしてある．

### 2026-11 に直したもの（v1.1.3）

- **ざ行・じゃ行の摩擦**：v1.1.2 は息の混じりを嫌って声門を閉じすぎた．雑音は人より 2–5 dB 弱いだけだったが，声が 10 dB 以上強く，差は −20 dB（人は −5）だった．声門を無声と有声の中間まで開き，その代わり離しの 70 ms 前に閉じ始める．差は −8 dB，離しのあとの HNR は 17–18 dB（人 18–19）のまま．長さも 10 ms 延ばした．
- **ら行の癖**：舌先だけが上がり，舌本体は前の母音のままだった．「あら」の F2 は接触へ向けて 1520 → 1380 Hz に下がっていた（人は約 2000 Hz に上がる）．弾きの形の舌本体を「い」の方へ 3–4 割寄せ，1850 Hz．「う」の後は専用の形がなく [d] と同じ形を使っていたので，足した．離しも速くした（τ 8 → 6 ms）．

### 2026-11 に直したもの（v1.1.4）

- **b d g の前後の母音が大きい**：閉鎖中に声を保つための声門（強い内転）は，同じ母音ならモーダルより 6–8 dB 大きい．閉鎖の 70 ms 前から離しの 40 ms 後まで口の開いた母音に重なり，頭のピークが 16 dB（人は 9）だった．声門の振動の振幅を 1 → 0.4 にし，その分わずかに閉じて，モーダルと同じ大きさにした．ピークは 9–10 dB．閉鎖中の声と HNR は変わらない．モーダルを変えたら，この振幅も選び直す．
- **t が強い**：離したあとの気息が強く，2–4 kHz が人より約 10 dB 強かった．声門を閉じ始めるのを離しの 25 → 55 ms 前にした．t の音はほぼ全部が気息で，舌の破裂は人より弱い（残っている）．k は変えない．

### 残っているもの

- 早口のざ行・じゃ行：1.5 倍速以上では母音の頭の息がまだ多い（じゃ行の HNR 8–12 dB．v1.1.2 は 13）
- t：舌の破裂が弱く，音のほとんどが気息
- 有声破裂：VOT がほぼ 0 ms（人は 10）．破裂の 4 kHz 以上がやや弱い
- ち：破裂の 2–4 kHz が強い．つ：6 kHz 以上が弱い（v1.1.2 でやや悪化）
- し・じ：全体にやや強い．s z ts：3–5 kHz が強い
- 鼻音：1–2 kHz が弱い
- は行，わ行，や行：詳しく見ていない
