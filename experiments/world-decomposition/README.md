# WORLD による実声と嘉音（v1.1.0、v1.1.3）の分解・差し替え

JVS の女性 51 名（voiceactress100 の5文、16 kHz）と、嘉音で合成した同じ文を WORLD（Harvest + StoneMask、CheapTrick、D4C）で分解した。統計を比べ、部品を差し替えて再合成した。

## 実行

    export KANON=v1-1-3 JVS_NPZ=<jvs-v1> VTL_LIB=<libVocalTractLabApi>
    python render.py jvs064 jvs053 jvs015  # 合成（out/<版>/audio）
    python stats.py && python plot.py      # 統計（results/stats-<版>.*）
    python swap.py jvs064 jvs053 jvs015    # 差し替え（out/<版>/swap/）
    python page.py                         # 試聴ページ（out/<版>/listen.html、v1.1.0 も並べる）
    ALIGN=<consonant-articulation/out/align.pkl> python vowels.py v1-1-0 v1-1-3       # 母音の中央だけ
    ALIGN=... python onset_peaks.py v1-1-0 v1-1-3                                     # 有声破裂の後の音量

numpy 1.26、scipy、matplotlib、pyworld、pyopenjtalk-prebuilt を使う。版の話者と規則は組で使う：v1.1.0 は 23aeb32 の backend と `accent.py`、v1.1.3 は 6f38671。`out/` は JVS の音声を含むので git に入れない。

## 合成音

- **ルール韻律**：`accent.py` の発話そのまま（F0 も継続長もルール）。
- **写し**：JVS の録音に DTW で合わせた継続長・ポーズと、録音の F0（分節ごとに3点）を入れた嘉音。最後に定数ラグと DTW で録音の時間軸に載せる。有声フレームの F0 誤差は中央値 17〜33 cent。

先頭のポーズが 100 ms 未満だと、VTL は調音を後ろへずらす一方で F0 ジェスチャを動かさない（`GesturalScore.cpp`）。最初の版はこれで F0 が約 90 ms 早かった。`accent.py` の同じ問題（rate > 1.2）は v1.1.1 の規則で直っている。

**母音の中央だけの雑音**（`vowels.py`、[results/vowels.json](results/vowels.json)）。3 kHz 帯の雑音/調波比は JVS −11.1 ± 3.0、v1.1.0 −5.5／−5.6、v1.1.3 −5.9／−6.1 dB（ルール／写しの平均）。同じ話者との差は写しで +7.1 → +6.6 dB。上の表で減った分は、母音の外側（子音と移行）で起きたか、有声と判定されるフレームが変わったことによる。**母音の息っぽさは残っている**。子音の修正はモーダルの声質を変えていないので、これは予想どおり。

**母音間のスペクトル差**（同）。5 母音の平均スペクトルの SD は 440–740 Hz で JVS 4.2–5.6 dB に対して 1.6–3.4 dB（v1.1.0、v1.1.3 とも）。ルール v1.1.3 では 3.4 kHz は小さく、3.7 と 4 kHz は大きい（4.7、4.0 → 7.7、7.9 dB）。F1 のあたりの母音の区別が弱い。F1 の鈍り（声門の漏れ）の可能性があるが確かめていない。

**有声破裂の後の音量**（`onset_peaks.py`）。b d g の後の母音の頭 60 ms のピーク（全体の RMS 比、60 Hz 以上）の中央値は JVS 8.9、v1.1.0 10.6／9.9、v1.1.3 **16.0／15.3 dB**（ルール／写し）。ほかの子音の後は 7.3、v1.1.0 7.8／8.1、v1.1.3 7.1／6.9 dB で変わらない。図で確かめた2例では離しの 30〜35 ms 後が最大。v1.1.3 で最大の8か所はすべて d・g に隣り合う所で、うち1つは d の前の母音、1つは g の閉鎖前だった（`voiced-plosive` は閉鎖の 70 ms 前から始まる）。`voiced-plosive` の声門（強い内転）から漏れの多いモーダルとの間を移る途中で声が強くなる、という仮説（未確認）。上の音量変動 9–25 Hz の増加とも合う。


## 韻律の組み替え（ポーズ・分節の長さ・F0）

試聴で一番自然さが上がったのは、ルールから写し（JVS 参照の時間と F0）への変更で、AP・E などの部品の差し替えでは明らかな向上がなかった（試聴者1名、盲検なし）。その変更の中身を `factor.py` で分けた。

    ALIGN=<align.pkl> python factor.py jvs064 jvs053 jvs015   # out/<版>/factor（12 の写しと 9 条件、108 個）
    python factor_page.py 013 017                             # 盲検の試聴ページ（out/<版>/prosody.html）

ポーズ P・分節の長さ T・F0 F をルールか録音のどちらから取るかの8通りと、F0 の幅だけ合わせたもの（R）、`accent.py` そのまま。P T F と R を比べやすいように、ルール側も話速（有音の合計時間）と F0 の平均を録音に合わせてある。

ポーズの位置：以前の写しは DTW で最も近い母音の終わりに置いており、強制アラインメントと比べると 009（jvs053、jvs015）、013（jvs015）、017（jvs053）で 1〜3 モーラずれ、012（jvs015）は文頭の空白をポーズと数えていた。ここではポーズをアラインメントの位置に固定して写しを作り直した。前の節の統計と差し替え（012 も含む）は直していない。012 は全話者のアラインメントが「はがね」の「は」の後にポーズを置くので、録音の読みが違う可能性があり（未確認）、この実験から外した。

試聴ページの並びは閲覧ごとに混ぜてあり、採点はブラウザに残る。

盲検の試聴（1名、013 と 017、3話者）：**F0 の効きが顕著**。点数は記録していない。

### ルールの F0 は何が違うか（`f0_rule.py`、[図](results/f0-rule.png)）

母音の中央の F0（半音、文ごとに平均を引く）を、JVS 女性 51 名の平均と比べた（001、009、013、017）。

- JVS どうしはよくそろう（1人と残りの平均の相関 0.86〜0.94）。ルールは 0.36〜0.56。平均との RMSE は 3.48 半音で、F0 を動かさない場合（3.60）とほぼ同じ。
- 図から：文頭でルールだけ高く始まって下がり続ける。複合語と固有名詞で核の位置や句の切り方が違う（五大明王、東寺、琉球王国、中山王など）。山と谷の差はルールの方が小さいことが多い。
- 6 パラメータ（ap、aa、α、β、lead）を 4 文の平均に合わせて 2.91、さらに核の位置（句の切れ目は固定）も合わせて 2.04 半音。同じ 4 文に当てはめた値なので、上限の目安にすぎない（新しい文では悪くなる）。
- したがって、パラメータだけでは足りず、アクセント（核の位置と句の切り方）の付け方の寄与が大きい。残りの 2 半音は句の切り方、句末、分節ごとの細かい動きなどと考えられるが、分けていない。

#### 振れ幅と、VOICEVOX を使わない学習

F0 の SD（100 文、モーラ中央、半音）は、JVS 平均 3.62・女性1人 3.92 に対し、今のルール 2.74、plus＋JVSに合わせた数値 2.76、めたん 3.15。つまり「JVS だけ抑揚が大きい」は事実。RMSE で合わせると、予測の SD は相関 × 3.62 に縮む（2.65 で、実測 2.76 とほぼ同じ）。SD を 3.62 にそろえた RMSE は、ルール 3.17、plus 2.98、plus＋合わせた数値 2.65、めたん 2.32、めたん＋plus 2.25 で、順位は変わらない。

アクセントの素性（句と核の位置、高低、呼気段落と文中の位置、前後の句、母音・子音の種類）だけから JVS 平均の F0 を予測する小さな学習器（`prosody_stat.py`、scikit-learn、音声の素性なし）。奇数 50 文で学習、偶数 50 文で採点：

| | RMSE | 相関 | SD |
|---|---:|---:|---:|
| ridge | 2.08 | 0.82 | 2.96 |
| GBM | 1.57 | 0.90 | 3.35 |
| ExtraTrees | 1.58 | 0.90 | 3.15 |
| 3つの平均（音に使った） | 1.60 | 0.90 | 3.07 |

対照（`prosody_stat_check.py`）：目標をモーラ間で混ぜると相関 −0.09。女性 25 名で学習し、別の 26 名の平均で採点しても 0.90。GBM で効いているのは、呼気段落の残りの長さ・文中の位置・高低・核からの位置。ただし、

- 目標も採点も JVS の平均で、同じ朗読文の体裁（voiceactress100）。平均に近いほど有利なので、女性1人の RMSE 1.60 と並ぶことは「人間並み」を意味しない。別の文体では確かめていない。
- 読点は JVS のポーズから置いた。実際の入力では、この正しい読点は手に入らない（全予測で同じ条件だが、呼気段落の素性が強いので影響は大きいはず）。
- JVS の音声は研究・非商用・個人利用に限る規約なので、学習したモデルを配る前に確認が要る。VOICEVOX を避けた理由と同じ種類の問題。

`prosody_range.py`：F0 だけを変え（時間はルール）、5 条件のうち 4 条件で文ごとの SD を JVS 平均に合わせた盲検ページ `out/<版>/prosody-range.html`（6 文）。要求した F0 との差の中央値は 7〜15 セント。振れ幅をそろえた盲検（聴取者1名、点数の記録なし）：学習モデルの評価が強い。

#### accent.py への組み込み（選択式）

`accent.render(..., f0_model=accent_f0.load("out/f0-model.pkl"))`。指定しなければ今までの規則のまま。モデルは JVS の統計から作るので git に入れない（`prosody_train.py` で作り直す。scikit-learn が要る。pickle なので、自分で作ったファイルだけを読む）。振れ幅は、平均化で縮んだ分を戻す係数 1.29 を掛ける。

読点への依存（偶数 50 文、相関 / RMSE。`prosody_commas.py`）：

| 学習 | JVS の読点 | 半分 | なし | 読み資料の全ポーズ | 書き手風 |
|---|---:|---:|---:|---:|---:|
| 今の規則（plus） | 0.68 / 2.67 | 0.59 / 2.98 | 0.53 / 3.14 | 0.67 / 2.72 | 0.47 / 3.33 |
| JVS の読点だけで学習 | 0.89 / 1.63 | 0.81 / 2.13 | 0.74 / 2.45 | 0.87 / 1.79 | 0.69 / 2.63 |
| 5 通りの読点を混ぜて学習（採用） | 0.89 / 1.69 | 0.84 / 1.95 | 0.81 / 2.15 | 0.88 / 1.76 | 0.78 / 2.24 |

正解の F0 は、JVS がポーズを置いた読み方のまま。「書き手風」は助詞で機械的に切った不自然な読点で、悲観的な条件。

頭高の句では、学習した F0 は第2モーラが第1モーラより高くなる。JVS の実測も同じ（頭高 57 句、第2−第1モーラ平均 +1.3 半音、女性の 68 % が上昇、第3−第2 モーラ −3.6）。規則は −2.8 / −1.6 で、下がるのが早い（遅下がりを表せない）。ただし、アラインメントの偏りや OpenJTalk の型の誤りは切り分けていない。

学習データは朗読の平叙文だけなので、疑問文の句末上昇（規則にもない）、一語文（「はい」の F0 がほぼ平ら）は学べていない。コーパス外の 12 文は `prosody_free.py`、盲検は `out/<版>/prosody-free.html`。結果はまだない。

## 注意

- 帯域は 8 kHz まで。D4C の帯域は 3 kHz と 6 kHz の2つしか使えないので、24 kHz に上げてから分析した。
- 声の聞こえの順位は付けていない（試聴が必要）。z は統計の外れ具合であって、知覚上の効きではない。
- 無声の判定は Harvest と D4C の両方が有声としたフレーム以外。気息で無声とされた母音の端が含まれるため、無声区間のスペクトルは子音だけではない。
- 写しは DTW で合わせており、短い子音で数十 ms ずれる。
- D の差し替えは話者の声道長の差を補正していない。実声の D を嘉音の S に載せると、フォルマントの位置が話者のものになる。
