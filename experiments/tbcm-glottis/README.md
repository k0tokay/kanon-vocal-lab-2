# 三角形 body-cover 声門(TBCM)

内喉頭筋5つの活動から声帯の姿勢・張り・質量を決め，空気流と結合して自励振動する声門モデルを VTL に加えた．選択名は "Triangular body-cover glottis"．嘉音用の話者ファイルは [fulkhisa-kanon-v1-1-0-tbcm.speaker](../../speakers/fulkhisa-kanon/fulkhisa-kanon-v1-1-0-tbcm.speaker)(v1.1.0 に4つ目の声門を足して選択しただけで，声道と既存の声門は同じ)．このモデルを持たない VTL では読めない．

## 構成

| 部分 | 内容 | 出典 |
|---|---|---|
| [LaryngealPosture](../../backend/LaryngealPosture.h) | LCA, IA, PCA, CT, TA の収縮応力(Kelvin モデル)と，披裂軟骨・輪状甲状関節の運動 | Titze & Hunter 2007, Titze 2006, Alzamendi ほか 2022 |
| [BodyCoverGlottis](../../backend/BodyCoverGlottis.h) | 応力と歪みから3質量のばね・質量を決める規則，三角形の縁，衝突，Titze 2002 の声門内圧 | Titze & Story 2002, Story & Titze 1995, Galindo ほか 2017, Alzamendi ほか 2022 |

論文は男性(声帯 16 mm)の値なので，嘉音は長さ 10 mm に幾何学的に相似縮小した(厚さ 2 mm，粘膜 1.5 mm，靱帯 1.5 mm，筋 3 mm)．筋肉側のパラメタは無次元の活動のまま使う．

数値は論文の表と本文のほか，Alzamendi ほかの公開 MATLAB コード(ライセンス表記なし)と照合した．コードは転載していないが，読んで確かめたので，独立実装ではない．

制御パラメタは F0，声門下圧，5筋の活動(0–1)，flutter．

### 論文に足した・変えたもの

1. **披裂軟骨の回転と筋の歪み**：LCA・IA・PCA の歪みは $-0.7\,\gamma\,\theta/L$ とした．0.7 は照合コードにある係数で，論文の本文には書かれていない．
2. **入口面の圧力**：下端の斜面に声門下圧がかかる(入口の長さ 0.6 mm)．VTL の Triangular glottis と同じ考え方．これがないと，縮小した声帯を強く閉じたとき吹き開けられず，振動しない条件が多かった．
3. **F0 制御(既定で有効)**：本来 F0 は筋活動と圧の結果だが，歌・TTS では F0 を指定したい．3質量の最低固有振動数が目標になる歪みを二分法で求め，1周期ごとの F0 の誤差で緩く補正する．振幅が小さいとき(立ち上がり・途切れ)は補正を止める．このため CT の活動は F0 に効かず，**声区は TA，閉じ方は LCA・IA・PCA，高さは F0** と分かれる．`F0 control = 0` にすると元の筋駆動に戻る．
4. **姿勢の速さ(嘉音は 12 倍)**：VTL のジェスチャは調音運動の時定数を自分で持つので，喉頭の力学をそのまま足すと二重に遅れる．

### 数値の安定性

初めは，強い内転と高い F0 で声道ソルバが発散した．原因は2つで，どちらも声門が数サンプルで閉じることによる．

- 気息雑音の流速を「1 kHz で平滑化した流量 ÷ ほぼ 0 の面積」で計算するので，閉鎖の瞬間に非物理的な値になる(雑音振幅は流速の3乗)．上限を肺圧のベルヌーイ速度にした．
- 声門部の台形積分が，閉鎖時の大きな抵抗で符号を変えながら鳴る．声門の枝だけ後退オイラーにした(`TdsModel::setRapidGlottalClosure`)．

これらは新モデルのときだけ働き，Geometric glottis 2025 と Triangular glottis の出力は以前とビット単位で同じ(2条件ずつ)．

## 検証

- **文献値(男性，/a/，800 Pa，F0 制御なし，入口面なし)**：F0 は 125/116/121 Hz(論文 116/105/115)，AC 流 371/360/346 cm³/s(395/368/372)，MFDR 483/370/420(711/376/648)，歪み −11.0/−12.6/−11.4 %(−9.5/−11.3/−10.3)，後部開口 1.5/2.8/1.1 mm²(1.4/3.0/1.1)．MFDR の2つは論文より 3 割以上低い．
- **安定性**：母音 6 種，150–800 Hz，300–1600 Pa，内転 3 段，TA 4 段の 1440 条件で発散 0．声が出ない条件は 636(高い F0，低い圧，極端な TA に集まる)．声の出た 804 条件のうち，F0 誤差が 2 % を超えたのは 50(flutter 25 % を含む)．
- **グライド**：180→620 Hz を 3 秒で上げ，平均誤差 0.06–0.09 半音．
- **文(tenki, ame)**：母音の F0 誤差は平均 0.48・0.37 半音(v1.1.0 は 0.15・0.17)．無声子音の直後に 30 ms ほど声の立ち上がりが遅れ，/ɯ/ など短い母音では有声区間が欠けることがある(母音の有声区間の割合は 0.84・0.95，v1.1.0 は 1.00・0.97)．
- **声の幅**：TA 0.06→0.40(330 Hz)で H1 に対する 2–5 kHz の落ちが 37→24 dB，内転 0.46→0.85(262 Hz)で 33→20 dB．ただし TA を上げると音量は 11 dB 下がる(実際の地声は圧も上げるので，圧と一緒に動かす必要がある)．

## 嘉音の既定

LCA .57，IA .40，PCA 0，TA .17，800 Pa．試聴の好み(H1−H2 8–16 dB，閉鎖率 .26–.33，わずかに漏れる)に近い領域から選んだ．`modal` のほか `falsetto`，`mixed`，`chest`，`pressed`，`breathy` を用意した．聴取では未評価．

## 限界

- 左右対称．片側麻痺などの左右差は扱わない(それを扱う a-TBCM は 2024 年に出ている)．
- 声区・歌唱での妥当性を調べた研究は TBCM にはなく，嘉音の大きさでの検証データもない．
- 話者の声門形状は筋活動を手で決めた．GUI は未対応で，声門図に "Unknown glottis type!" と出る．
- ジェスチャスコアの F0 は 108 半音(約 512 Hz)が上限なので，それより高い音はパラメタを直接渡して合成する．

## やさしい声と少年声

[gentle.py](gentle.py) が候補の合成と測定をする．目安にした特徴量は，林・森勢「女性声優の演技音声における年齢・性別の表現と関連する音響特徴量」のもの([features.py](features.py))．論文は WORLD で測っているので，表の値は論文の値と直接比べず，このモデル同士で比べる．

論文の要点：少年は幼い少女より基本周波数が低く(260 対 337 mel)，スペクトル重心は中高生の少女より高い(1801 Hz 対 1694 Hz，幼い少女は 1958 Hz)．1 kHz 以上の傾斜は急(−16.4 dB/oct，大人の女性は −14.1)，H1−H3 は小さい(8.1 dB 対 12.9 dB)．聴取の主成分得点を説明する回帰係数は，大人の女性らしさ(色っぽい，品，落ち着き)で傾斜 +.76・平均パワー −.40・F0 +.35，少年らしさ(張り，太い，迫力)で F0 −1.27・傾斜 −.86・パワー +.83・F0 の変動 +.61．**傾斜とパワーは2つの主成分で符号が逆**なので，「やさしい」を強めるほど少年らしさの軸からは離れる．第3主成分(寄与率 5 %)の話で，10 名の声優と1文の結果であることに注意．

|---|---|---|---|---|---|---|---|---|---|---|
| 今の TBCM | .57 / .40 / .17 | −34 dB | 1.0 | 0 | 228 | 1293 | −16.1 | 0.2 | .52 | −11.6 |
| やさしい 弱 | .54 / .38 / .11 | −32 | 1.0 | 0 | 228 | 895 | −10.6 | 3.6 | .88 | −9.9 |
| やさしい 中 | .51 / .36 / .10 | −30 | 1.0 | 0 | 229 | 1056 | −8.8 | 5.5 | .94 | −10.3 |
| やさしい 強 | .49 / .34 / .08 | −29 | .95 | 0 | 229 | 1392 | −7.4 | 7.4 | .96 | −12.0 |
| やさしい 中 F0 だけ下げる | 同じ | −30 | 1.0 | −4 半音 | 182 | 1079 | −8.9 | 4.4 | .92 | −9.3 |
| 少年 息を少し残す | .54 / .38 / .14 | −31 | 1.05 | −4 半音，抑揚 1.2 倍 | 182 | 1022 | −12.1 | 2.4 | .76 | −7.8 |
| 少年 張り | .55 / .38 / .18 | −32 | 1.1 | −4 半音，抑揚 1.2 倍 | 182 | 1297 | −15.6 | 0.5 | .65 | −6.5 |

2文(ame, tenki)の母音の平均．「周期間の乱れ」は 2–6 kHz の自己相関で測った(1 に近いほど雑音的)．やさしい側の重心は，低域が強くなる効果と高域の雑音が増える効果が打ち消し合うので，単調でない．

- 喉頭を上げる(HY を +8 mm まで)操作は重心をほとんど変えなかった．嘉音の形状はもともと HY が下限にあり，動かせる量が小さい．
- 厚さ .15–.30 cm，粘膜の剛性 2000–5000 dPa もほとんど効かない．長さを 1.15 cm にすると音量が 3 dB 上がり，傾斜が 1 dB/oct 急になる．
- 無声の声門形状を 25 ms 早く閉じ始めると，母音の有声区間が 2–6 ポイント増えた(`synth.advance_closing`)．

話者ファイルは `…-tbcm-gentle`(やさしい 中)と `…-tbcm-gentle-boy`(少年 息を少し残す．F0 の下げは話者ではなくスコア側で与える)．試聴は [results/gentle](results/gentle)．聴取は未評価．

## 滑らかさと息を分けて見る(LCA と PCA の同時活動)

[smooth.py](smooth.py)．F0 制御を入れたモデルでは，内転・外転の3筋(LCA, IA, PCA)は声門の**声帯突起の間隔(VP)** と **後部(軟骨部)の開口(PGO)** の2つを通してだけ音に効く．同じ VP と PGO になる組み合わせは同じ音になる．

| LCA / IA / PCA | VP (mm) | PGO (mm²) | H1−H3 | 倍音の重心 (Hz) | 息 (dB) |
|---|---|---|---|---|---|
| .51 / .36 / 0 (前回のやさしい中) | .30 | .96 | 5.9 | 688 | −23.5 |
| .62 / .255 / .057 (手動) | .31 | 1.09 | 6.1 | 687 | −22.7 |
| 1.0 / .255 / .22 (手動) | .21 | .50 | 2.5 | 781 | −29.0 |
| 1.0 / .255 / .23 | .26 | .58 | 3.7 | 739 | −27.7 |
| .80 / .40 / .12 | .22 | .45 | 2.3 | 781 | −29.2 |
| **.55 / .50 / 0** | .23 | .53 | 2.8 | 768 | −28.6 |

- 気息 −30 dB．息は気息を切った同じ文との 3–10 kHz の差を，母音の全体の強さに対する dB で表した．倍音側の値は気息 −60 dB で測った．
- LCA を 100 % にして PCA で打ち消す設定は，**PCA 0，IA を .50 に上げた設定とほぼ同じ**になる(倍音の重心で 13 Hz，息で 0.4 dB の差)．LCA と PCA は VP を逆向きに動かす(この点では LCA 1 % あたり −.02 mm，PCA 1 % あたり +.045 mm)ので打ち消し合い，PGO は LCA と IA が閉じる側に効く．
- LCA を下げて PCA 0 のまま漏らすと(前回のやさしい中)，VP も PGO も大きくなり，倍音は一番滑らかだが息も一番多い．VP が同じでも PGO が大きいほど息が増える．滑らかさ(倍音)は主に VP，息は VP と PGO と気息の強さで決まる．
- **気息の強さ(dB)は倍音と独立**なので，滑らかさを変えずに息だけ増減できる：.51 / .36 / 0 で −35 dB なら −28.6 dB，−40 dB なら −33.3 dB．

話者ファイル `…-tbcm-smooth` は .54 / .47 / 0，TA .10，気息 −33 dB．聴取は未評価．**試聴の10番(.51 / .36 / 0，TA .10，気息 −35 dB)を [v1.2.0](../../speakers/fulkhisa-kanon/fulkhisa-kanon-v1-2-0.speaker) とした(暫定)．** 試聴は [results/smooth](results/smooth)．

## 自然な F0(F0 制御なし)とそのヤコビアン

[natural.py](natural.py)．`F0 control = 0` では，F0 は筋活動・圧・声帯の寸法だけで決まる．制御パラメタ f0，スコアの F0，flutter は使われず，CT が効く．v1.2.0 の設定(嘉音の定常 /a/，8000 dPa)では 258.8 Hz．

v1.2.0 の近くでの変化(筋と収束は活動・値 +0.1，圧と寸法は +10 %．微分は [vtlmap](../vtlmap/README.md) の `jacobian`)：

| | F0 | H1−H2 | CQ | レベル |
|---|---|---|---|---|
| CT | +26.9 % | −1.5 dB | −.02 | −0.5 dB |
| PCA | −16.9 % | +1.5 | −.05 | −9.5 |
| TA | −12.3 % | +2.8 | +.05 | −0.8 |
| LCA | +7.0 % | +0.5 | +.05 | +4.5 |
| IA | −1.0 % | 0 | 0 | +0.5 |
| 静止長 | −6.1 % | −1.8 | 0 | +3.1 |
| 圧 | +1.9 % | −0.8 | 0 | +2.7 |
| 粘膜の深さ | −1.7 % | +0.4 | 0 | −0.6 |

厚さ・靱帯と筋の深さ・剪断弾性率・収束・後部の開口の倍率は，F0 への効果が 0.4 % 以下．H1−2k は声門流の零点が倍音をまたぐと跳ぶので，微分は粗い．

`python3 natural.py 203` は F0 だけを 203 Hz に下げる最短の動き(最小ノルム)も求める．筋と圧だけなら CT .115→.070，TA .10→.12，PCA 0→.03，LCA .51→.50．H1−H2 は 7.5 dB 上がり，レベルは 3.7 dB 下がる．寸法も動かし，H1−H2，H1−2k，CQ，レベルを保とうとすると静止長が 1.68 cm まで伸びる(H1−H2 は 4.2 dB 上がったまま)．

## 録音からの声帯の推定

「あ」の長音の録音(1名，スマートフォン，F0 約 200 Hz．録音は置いていない)から，TBCM の筋活動・圧・寸法を推定した．嘉音の声道は変えない．[v1.3.0](../../speakers/fulkhisa-kanon/fulkhisa-kanon-v1-3-0.speaker) はその1つ(下の D)を使っている．

### 合わせているもの

1. 録音を 50 ms ごとに測り，F0 と 1–22 倍音の大きさ，倍音の間の雑音の大きさを中央値で取る．位相と波形は使わない．
2. TBCM を嘉音の声道で鳴らし，**声門の流れの微分**の倍音を取る(口から出る音ではない)．
3. それに**録音側の声道**(F1–F5 と帯域幅)を掛け，録音の倍音と比べる．声帯と録音側の声道を同時に動かす．
4. 誤差の許容は 1–4 倍音が 1 dB，5–9 倍音が 2.5–4 dB，それより上が 5 dB．F0 は 0.4 %．パラメタには嘉音の値と流れの大きさ(p-p 220 cm³/s，対数の標準偏差 .35)を中心とする事前分布を置く．
5. ランダムな 1000 点から良い3点を選び，CMA-ES で探す．

| | 録音側の未知数 | 手順 |
|---|---|---|
| A / B | 声道のみ．5 倍音を無視 | [estimate.py](estimate.py) |
| C | 声道のみ．5 倍音を含む | [estimate2.py](estimate2.py) |
| D | C ＋ 1010 Hz 付近の零点 ＋ マイクの低域の落ち | `estimate2.py 1 --notch` |
| 嘉音固定 | なし．嘉音の声道から出た音をそのまま録音と比べる | [estimate3.py](estimate3.py) |

### 推定された値(D)

最初の録音から．括弧は別の録音(長い撮り直し，鼻の抜けや舌の位置を変えたもの)での幅．

| | 値 |
|---|---|
| 声門の閉じている割合 CQ | .21(.17–.25) |
| H1−H2(声門流の微分) | 9–10 dB(9–13) |
| 声帯突起の間隔 VP | .24 mm(前舌寄りの「あ」を除き .18–.43) |
| 後部の開口 PGO | .62 mm²(.48–1.3) |
| 圧 | 8940 dPa(絶対レベルがないので事前分布で決まる) |
| LCA / IA / PCA / CT / TA | .54 / .64 / .10 / .23 / .46 |

- **声の性質は再現できるが，筋活動は一意に決まらない．** 既知の値で作った音から戻すと CT .12 / TA .17 が .19 / .32 になった．CQ，H1−H2，VP，PGO が近い別の筋の組が，同じくらいよく合う．
- 内転の組合せ以外に，録音側の声道も一緒に決めているので，誤差が声道に逃げている可能性がある．
- 前舌寄りの「あ」では解が決まらなかった(VP が 3 通りで .53–1.16 mm)．

### 5 倍音(約 1010 Hz)の谷

最初の録音では 5 倍音だけが前後より 25 dB 前後弱く，全極の声道では説明できない(9 dB 弱いはずのところが 34 dB 弱い)．撮り直した長い録音(17.5 秒)では，同じ人の「あ」なのに谷がまったく出なかった．

- **声帯ではない**：両方の録音を1つの声帯で説明できた(声帯を入れ替え，録音側の声道だけ合わせ直した誤差は 10.0 と 22.2，それぞれの最良は 8.5 と 21.0)．
- **肺圧でも，後半の疲れでもない**：谷の深さと大きさの相関は −.29 と +.13．モデルでは圧を 8000→5000 dPa に下げると谷が約 6 dB 深くなるので，向きは合うが，録音どうしの差(約 25 dB)には足りない．
- 前舌寄りの「あ」では −9→−22 dB と深くなり，後舌寄りではほぼ出ない．鼻をつまむと逆に +4〜+10 dB 出っ張る．舌の位置，鼻への抜け，マイクや部屋のどれが主かは**決まっていない**．
- 1つの録音の 5 倍音に声帯を合わせてはいけない，ということだけは言える．

### 嘉音の声道に入れると変わる

嘉音の「あ」の山は約 830 / 1490 / 3500 Hz，録音は約 700 / 1150 / 2940 Hz．倍音のうち強まるものがずれる．声道を変えずに声帯だけで録音に近づける(嘉音固定)と，倍音ごとの誤差は 42.0→24.6(最初の録音)，58.7→33.2(撮り直し)に下がるが，息漏れを増やす(PGO .62→2.1 mm²)ことで声道の違いを肩代わりした解になった．帯域ごとの比較では 24.3→21.0，23.9→19.2 でほぼ変わらない．声帯の推定が正しくても，声道が違えば聞こえは変わる．

### 雑音は思ったより聞こえに効く

試聴では，倍音を合わせるだけでなく，雑音を足すかどうかで印象がはっきり変わった(聴取は1名)．

- **息(声門の雑音)**：倍音の間の雑音に合わせると，嘉音の声道では −30 dB(cutoff 1000 Hz)前後．[estimate_noise.py](estimate_noise.py)．ただし録音の雑音には部屋の音も入るので**上限**．最初の録音では 4 kHz 以下の雑音が，声の前の雑音(吸気や部屋の音)と同じ高さだった．撮り直しの録音では，2–4 kHz だけが声の前より 16 dB 高く，声由来らしい．そこの値は −24〜−48 dB と広く，決まらない．
- **部屋の雑音**：声の前の区間の RMS は声より 27–34 dB 低い．**声帯のモデルには足せなかった**ので，パラメタを加えた(下)．

### 背景雑音のパラメタ

部屋やマイクの雑音は声門の流れとは別なので，口から出た音に足す．定常のガウス雑音に 1 次の低域通過と 50 Hz の高域通過を掛け，指定した RMS に合わせる．乱数の種は固定で，同じ条件なら同じ音になる．無声区間や無音の区間にも鳴り続ける．

| static param | 意味 | 既定 |
|---|---|---|
| `Background noise level` (dB) | 出力 1 に対する RMS．**−120 dB は無効** | −120 |
| `Background noise cutoff` (Hz) | 低域通過の遮断周波数 | 300 |

- TBCM と Geometric glottis 2025 にある．計算は `Synthesizer::getBackgroundNoiseSample`．既定では出力は以前とビット単位で同じ(v1.1.0，v1.2.0，JD2 の文で確認)．
- cutoff 300 Hz は，最初の録音の声の前の雑音の傾き(100–500 Hz に対して 0.5–1 kHz −4，1–2 kHz −8，2–4 kHz −13 dB)に近い．撮り直しの録音の傾きはこれより急．
- 声の定常部の RMS は −32 dB 前後なので，−65 dB にすると声より約 33 dB 低い(撮り直しの録音に近い)．
- 話者ファイルに書く値なので，これを読まない VTL では読めない．

### 使い方

```sh
python3 estimate.py 録音.wav                       # 測定(build/est/target.json)と A・B
python3 estimate2.py 1 --notch                     # D (結果は build/est/)
TARGET=full2 python3 estimate3.py 1 harm           # 嘉音の声道を固定(harm | band)
python3 estimate_noise.py build/est/D.json 録音.wav 2.0   # 息の強さ
python3 estimate_spread.py                         # A の局所的な不確かさ
python3 estimate_speaker.py build/est/D.json -30 1000 出力.speaker
```

録音と `build/est/` はコミットしていない．

### v1.3.0

D の筋活動・圧・寸法に，息 −30 dB，cutoff 1000 Hz を付けたもの．背景雑音は既定(無効)．F0 制御は有効(1)で，0 にすると自然な F0 は約 202 Hz．

- 203 Hz の定常 /a/：H1−H2 10.2 dB，CQ .21．圧 8940 dPa で 150–523 Hz は F0 の誤差 0.2 % 以内．440 Hz は弱く(−44 dB)，660 Hz は 8940 dPa では F0 が 626 Hz に外れ，12000 dPa なら合う．高い声は圧を上げる必要がある．
- 文(tenki, ame)で v1.2.0 と同じように F0 に追従し，発散はない．母音の強さの差は数 dB．
- 声帯の既定の形(modal, default)以外は v1.2.0 と同じ．寸法が変わったので，falsetto，pressed などの形は音が変わっているが，確かめていない．
- 母音は嘉音の声道のままなので，録音した声とは似ていない．

### 限界

- 1 人，1 台のマイク，圧縮音声(約 63 kbps)，絶対レベルなし．聴き比べも 1 名．
- 録音の 1・2 倍音の差が推定より 4–5 dB 小さく，合わなかった．マイクの低域の落ちか，強い内転か，TBCM の波形の癖かは分からない．
- 嘉音の舌・あご・唇の形も一緒に動かせば F1・F2 は録音へ寄せられるはずだが，試していない．F3 は声道の長さの違いが残る．
