# 嘉音 v1.1.0 の子音の診断と v1.1.1

v1.1.0 の子音を音節と 5 文で測り，JVS 女性 51 人の同じ文の同じトークンと比べた．原因のはっきりしたものを直し，話者 v1.1.1 と日本語規則にまとめた．モーダルの声質，母音，解剖は v1.1.0 のまま．v1.1.0 のファイルは変えていない．

JVS の音声は統計との比較にだけ使い，声の素材には入れていない．git にも入れていない（`out/` は無視）．

## 子音ごとの診断（v1.1.0）

値は「JVS の中央値 → v1.1.0」．z は 51 人の散らばりで割ったもの．

どの子音にも共通するのは長さで，同じモーラ長（JVS 140 ms，規則 135 ms）に対して子音だけが 0.5–0.7 倍だった（`durations.py`）．VTL は閉鎖を「区間 − VOT」に正確に合わせるので，短い区間はそのまま短い閉鎖になる．

v1.1.0 は以前の ɕ の修正（`consonant-tuning/edits/alveolopalatal.json`）を受け継いでいなかった．

## 直したもの

**話者 v1.1.1**（`build.py`，変更は [results/shapes.json](results/shapes.json)）

- s, ɕ, ç, t, 後部歯茎閉鎖, k, 両唇：顎と唇を開いて歯の隙間を 0.6 cm² 以上にし（VTL では舌は顎と一緒に動かない），舌を最小限動かして狭めの位置と戻りの余裕を JD2 並みにした．ɕ は TS2 0.5，TS3 0.893（歯擦音の雑音），k は TS1 = TS2 = 0．
- ɸ：唇 0.12 cm²．弾き音は歯の隙間だけ広げた．
- 声門 `voiced-plosive`：内転（x 0.025/0.055，後部隙間 0.0015，振幅 1）．`voiceless-fricative`：0.17/0.17，0.03．

**規則**

- `GesturalScore.cpp`：区間のラベル `stop = ja` のときだけ，VOT を p 18，t 20，k 28，b 0，d 8，g 10 ms に固定し，無声の離しの時定数を 8 ms，声門の動作を閉鎖の離しの 25 ms 前まで（有声は閉鎖の 50 ms 前から）にする．ラベルのない区間の動作は変わらない．
- 同：`s\` `z\` を，破裂の離しを速くする一覧に加えた．
- `accent.py`：子音長を JVS に合わせた．母音の後の「じゃ行」は [ʑ]．鼻音の口蓋帆の開きを 2 倍（休止中の開きは変えない）．話速 1.2 超で文頭の休止が 100 ms を割り全体がずれる不具合も直した．

## 結果

5 文，JVS 51 人に対する z の絶対値の平均と，2 を超える割合（12 類，全部の版で測れた 205 個の測度）：

| | 平均 \|z\| | 2 超 |
|---|---|---|
| v1.1.0 | 1.61 | 29 % |
| v1.1.0 ＋新しい規則 | 1.51 | 24 % |
| v1.1.1 ＋新しい規則 | 1.16 | 14 % |

| 測度 | JVS | v1.1.0 | v1.1.1 |
|---|---|---|---|
| k t 閉鎖（ms） | 43 | 20 | 30 |
| k t 破裂 2–4 / 4–8 kHz（dB） | −15 / −16 | −27 / −27 | −19 / −19 |
| b d g 閉鎖中の低域（dB） | −17 | −33 | −21 |
| b d g VOT（ms） | 10 | 22 | 14 |
| s 6 kHz 以上（dB） | −6 | −14 | −7 |
| ɕ 重心（kHz） | 5.7 | 4.1 | 5.1 |
| ɕ 6 kHz 以上（dB） | −3 | −19 | −7 |
| tɕ 重心（kHz） | 5.5 | 3.7 | 5.2 |
| z 6 kHz 以上（dB） | −2 | −15 | −7 |
| tɕ 閉鎖（ms） | 31 | 15 | 24 |
| m n 1–2 kHz（dB） | −10 | −31 | −24 |

全部の表は [results/table.txt](results/table.txt)，形状の静的な値（JD2 との比較つき）は [results/static.txt](results/static.txt)，試聴は [results/listen.html](results/listen.html)（合成音だけ）．

**悪くなったもの**：b d g の破裂は 1–2 kHz が −27 → −18 dB（JVS −13）に近づいた一方，2–4 kHz は −27 → −31（−18），4 kHz 以上は −30 → −36（−21）と離れた．声門を絞ったので離しの気流が減ったため．tɕ は全体のレベルが JVS より 8 dB 強い（v1.1.0 は差なし），ʑ は 1 kHz 以上が 10 dB 強い（v1.1.0 は 5 dB）．m n の 3 kHz は JVS より 12 dB 強い（v1.1.0 は 6 dB）．

新しい規則は v1.1.1 と組で使う．v1.1.0 のまま規則だけ替えると，有声破裂は閉鎖が伸びたぶん声がさらに消える（閉鎖中の低域 −54 dB）．

**残ったもの**：ɾ の接触，鼻音の 1–2 kHz，s と ç の 3–5 kHz の強さ，h の評価．無声閉鎖の静かさ（−72 dB）は JVS の収録の背景雑音（−46 dB）との差で，失敗とは見なさない．p は 5 文に出ず，比較は音節の観察だけ．JVS の窓は 8 kHz まで．

## 手順

```
align.py                    JVS の強制アラインメント → out/align.pkl
compare.py v111=話者 ...    5 文を合成して JVS と比べる → results/compare-*.json
show.py v110 rules v111     表
durations.py                子音長
build.py                    v1.1.0 → v1.1.1
glottis_scan.py             声門形の走査
listen.py                   試聴ページ（先に consonant-tuning/ctune.py run out/base, out/new）
cdiag.cpp                   口腔内圧・流量・声門の時系列
```

`compare-v110.json` は 2de4607 のライブラリと `compare.py --old-rules` で作った．環境変数 `JVS_NPZ`，`VTL_LIB`，`VTL_SPEAKER` が要る．
