# 嘉音 v1.1.0 の子音の診断と v1.1.1，v1.1.2

v1.1.0 の子音を音節と 5 文で測り，JVS 女性 51 人の同じ文の同じトークンと比べた．原因のはっきりしたものを直し，話者 v1.1.1，v1.1.2 と日本語規則にまとめた．モーダルの声質，母音，解剖は v1.1.0 のまま．v1.1.0，v1.1.1 のファイルは変えていない．

JVS の音声は統計との比較にだけ使い，声の素材には入れていない．git にも入れていない（`out/` は無視）．

## 直したもの（v1.1.1）

「規則」は，区間（子音の名前と長さ）を作る `accent.py` と，それをジェスチャ（どの形状へ，いつからいつまで，どの時定数で）に直す `GesturalScore.cpp` のこと．目標の形状を持つ話者ファイルと対にして言う．診断の見方と合わせて [docs/子音の調音.md](../../docs/子音の調音.md) にまとめた．

**話者 v1.1.1**（`build.py`，変更は [results/shapes.json](results/shapes.json)）

- s, ɕ, ç, t, 後部歯茎閉鎖, k, 両唇：顎と唇を開いて歯の隙間を 0.6 cm² 以上にし（VTL では舌は顎と一緒に動かない），舌を最小限動かして狭めの位置と戻りの余裕を JD2 並みにした．ɕ は TS2 0.5，TS3 0.893（歯擦音の雑音），k は TS1 = TS2 = 0．
- ɸ：唇 0.12 cm²．弾き音は歯の隙間だけ広げた．
- 声門 `voiced-plosive`：内転（x 0.025/0.055，後部隙間 0.0015，振幅 1）．`voiceless-fricative`：0.17/0.17，0.03．

**規則**

- `GesturalScore.cpp`：区間のラベル（いまの名は `timing = ja`）のときだけ，VOT を p 18，t 20，k 28 ms に固定し，無声の離しの時定数を 8 ms，声門の動作を離しの 25 ms 前までにする．ラベルのない区間の動作は変わらない（.ges の一致で確認）．
- 同：`s\` `z\` を，破裂の離しを速くする一覧に加えた．
- `accent.py`：子音長を JVS に合わせた．母音の後の「じゃ行」は [ʑ]．鼻音の口蓋帆の開きを 2 倍（休止中の開きは変えない）．話速 1.2 超で文頭の休止が 100 ms を割り全体がずれる不具合も直した．

## v1.1.2：有声の破裂・摩擦，ら行，早口

試聴で残った三つの問題を調べた．話者は `build112.py` の 2 か所だけ変えた（弾きの TS3 を −0.28，`voiced-fricative` を 0.12/0.13，後部隙間 0.015，振幅 0.8）．残りは規則．モーダル，母音，ほかの形状は v1.1.1 と同じ．

**有声破裂**（`voicing.py`，`internal.py`，`voiced_scan.py`）．v1.1.1 では，

- 声門の動作は閉鎖の 50 ms 前に始まるが，τ 10 ms では閉鎖の時に半分しか閉じていない．漏れが口腔を満たし，口腔内圧はすぐ肺圧の 50–75 %（g は 90 %）になる．VTL は 75 % あたりで振動を止める．低域は −17〜−26 dB で，離しの 20 ms 後まで戻らない．
- 閉鎖が b 60，d 47，g 55 ms（JVS は約 30．g は弱化していて 1–8 kHz で −26 dB しか落ちない）．
- 閉鎖中は 500 Hz より上の倍音がほとんどない．

新しい規則：

| | 閉鎖の始め（区間の頭から） | 離し（区間の終わりから） | τ 閉じ／開き | 口蓋帆 |
|---|---|---|---|---|
| b | 15 ms | −15 ms | 12／14 ms | 0.04 cm² |
| d | 5 | −20 | 10／12 | 0.04 |
| g | 22 | −25 | 16／14 | 0.02 |

声門は閉鎖の 70 ms 前から離しの 10 ms 後まで `voiced-plosive`，τ 6 ms（声門の τ の下限は 10 ms に黙って切られていたので 5 ms にした）．短い区間では時間を縮める．口蓋帆は鼻音・休止の後と閉鎖 12 ms 以下では開けない．VTL は口腔の膨張を計算しないので，漏らす以外に圧を逃がす道がない．

離しの後の HNR は JVS と同じに戻る．b d は有声有気音ではない．

**有声摩擦**．こちらは有声有気音になっていた．声門が [h] 並みに開き，離しの後 40 ms 開いたまま（流量 500–720 cm³/s，母音は 350）．母音の頭の HNR は 8–14 dB（JVS 17–19）．開きを減らし，10 ms 早く戻して 16–17 dB．摩擦の中の声は −7〜−9 dB で，JVS（−14〜−27）より有声のまま．

**ら行**．約 9 ms 完全に閉じ，流量 0．面積は動きの 2 % で 0 → 0.15 cm² に飛ぶので，位置では半端な接触を作れない．TS3 が −0.2〜−0.35 で開く側面の流路（約 0.06 cm²）と，閉鎖とみなす面積 0.11 cm²（`contact_cm2`）で作った．1–8 kHz の落ち込みは −45 → −23 dB（JVS −23）．TS3 が 0.2 を超えると雑音源になる．

**早口**（`rate.py`，[rate-v111](results/rate-v111.json)，[rate-v112](results/rate-v112.json)）．話速 1 = 135 ms／モーラ．話速 0.5 の時の調音を 1 として，到達率の中央値．

| | v1.1.1：1.5 倍 | 2 倍 | v1.1.2：1.5 倍 | 2 倍 |
|---|---|---|---|---|
| s | 0.94 | 0.86 | 0.99 | 0.98 |
| ɕ | 0.97 | 0.92 | 0.99 | 0.99 |
| z | 0.89 | 0.80 | 0.99 | 0.99 |
| じゃ行 | 0.94 | 0.85 | 0.98 | 0.91 |
| ç ɸ | 0.90 | 0.79 | 0.95 | 0.89 |
| k t（形） | 0.84 | 0.77 | 0.89 | 0.81 |
| k t（声門） | 0.48 | 0.43 | 0.67 | 0.69 |
| tɕ（声門） | 0.74 | 0.58 | 0.99 | 0.97 |
| s（声門） | 0.89 | 0.76 | 0.99 | 1.00 |
| b d g（声門） | 0.83 | 0.76 | 1.00 | 1.00 |
| m n（口蓋帆） | 0.77 | 0.50 | 0.90 | 0.90 |
| m n（形） | 0.86 | 0.81 | 0.86 | 0.81 |
| 弾き | 1.0 | 1.0 | 1.0 | 1.0 |

原因は τ = 10 ms と 100 ms の移行が子音の長さによらず固定だったこと．閉鎖は逆算されるので必ず届く（2 倍で k t は 46 → 17 ms に縮む）．直したのは，摩擦の τ = (長さ + 10 ms)/11（5–10 ms），有声以外の破裂の声門の τ，鼻音の口蓋帆の動作を 100 ms 以上，有声摩擦の声門は 53 ms 以上先に動かす．無声摩擦の声門はやや長く開ける．`accent.py` の「ふ」の書き換えは区間の中点で判定していて 1.75 倍以上では外れ，[f] のままだったので，重なりで判定する．

残り：母音は届かない（0.5 Bark 超が 2 倍で 52 %，1 倍で 20 %）．z は 2 倍で雑音が弱い（6 kHz 以上 −11 dB，v1.1.1 は −8）．ɕ は 1.5 倍以上で 6 kHz 以上が −14 dB に落ちる（v1.1.1 は −12）．早口の摩擦中の声（s −9，ɕ −1 dB）は，中の声門が開ききっているので大部分は窓が隣の母音を拾ったもの．

## 手順

```
align.py                    JVS の強制アラインメント → out/align.pkl
compare.py v112=話者 ...    5 文を合成して JVS と比べる → results/compare-*.json
show.py v110 rules v111 v112 表
durations.py                子音長
voicing.py                  離しに揃えた低域・1–8 kHz・HNR・傾きの軌跡（JVS と）
internal.py                 口腔内圧・声門・流量・面積の時系列（cdiag.cpp）
voiced_scan.py              有声音の規則と声門形の走査
rate.py v112=話者           早口の到達率
glottis_scan.py             声門形の走査
build.py, build112.py       v1.1.0 → v1.1.1 → v1.1.2
listen.py, listen112.py     試聴ページ
```

`compare-v110.json` は 2de4607 のライブラリと `--old-rules`，`rules` `v111` は a86f77e のライブラリと `--v111-rules` で作った．環境変数 `JVS_NPZ`，`VTL_LIB`，`VTL_SPEAKER` が要る．
