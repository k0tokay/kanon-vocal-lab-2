# 嘉音 v1.1.0 の子音の診断と v1.1.1〜v1.1.4

v1.1.0 の子音を音節と 5 文で測り，JVS 女性 51 人の同じ文の同じトークンと比べた．原因のはっきりしたものを直し，話者 v1.1.1〜v1.1.4 と日本語規則にまとめた．モーダルの声質，母音，解剖は v1.1.0 のまま．v1.1.0〜v1.1.3 のファイルは変えていない．

JVS の音声は統計との比較にだけ使い，声の素材には入れていない．git にも入れていない（`out/` は無視）．

**話者 v1.1.1**（`build.py`，変更は [results/shapes.json](results/shapes.json)）

- s, ɕ, ç, t, 後部歯茎閉鎖, k, 両唇：顎と唇を開いて歯の隙間を 0.6 cm² 以上にし（VTL では舌は顎と一緒に動かない），舌を最小限動かして狭めの位置と戻りの余裕を JD2 並みにした．ɕ は TS2 0.5，TS3 0.893（歯擦音の雑音），k は TS1 = TS2 = 0．
- ɸ：唇 0.12 cm²．弾き音は歯の隙間だけ広げた．

**規則**

- 同：`s\` `z\` を，破裂の離しを速くする一覧に加えた．
- `accent.py`：子音長を JVS に合わせた．母音の後の「じゃ行」は [ʑ]．鼻音の口蓋帆の開きを 2 倍（休止中の開きは変えない）．話速 1.2 超で文頭の休止が 100 ms を割り全体がずれる不具合も直した．

## v1.1.2：有声の破裂・摩擦，ら行，早口

試聴で残った三つの問題を調べた．話者は `build112.py` の 2 か所だけ変えた（弾きの TS3 を −0.28，`voiced-fricative` を 0.12/0.13，後部隙間 0.015，振幅 0.8）．残りは規則．モーダル，母音，ほかの形状は v1.1.1 と同じ．

**有声破裂**（`voicing.py`，`internal.py`，`voiced_scan.py`）．v1.1.1 では，

- 声門の動作は閉鎖の 50 ms 前に始まるが，τ 10 ms では閉鎖の時に半分しか閉じていない．漏れが口腔を満たし，口腔内圧はすぐ肺圧の 50–75 %（g は 90 %）になる．VTL は 75 % あたりで振動を止める．低域は −17〜−26 dB で，離しの 20 ms 後まで戻らない．
- 閉鎖が b 60，d 47，g 55 ms（JVS は約 30．g は弱化していて 1–8 kHz で −26 dB しか落ちない）．
- 閉鎖中は 500 Hz より上の倍音がほとんどない．

新しい規則：

| | 閉鎖の始め（区間の頭から） | 離し（区間の終わりから） | τ 閉じ／開き | 口蓋帆 |
|---|---|---|---|---|
| b | 15 ms | −15 ms | 12／14 ms | 0.04 cm² |
| d | 5 | −20 | 10／12 | 0.04 |
| g | 22 | −25 | 16／14 | 0.02 |

声門は閉鎖の 70 ms 前から離しの 10 ms 後まで `voiced-plosive`，τ 6 ms（声門の τ の下限は 10 ms に黙って切られていたので 5 ms にした）．短い区間では時間を縮める．口蓋帆は鼻音・休止の後と閉鎖 12 ms 以下では開けない．VTL は口腔の膨張を計算しないので，漏らす以外に圧を逃がす道がない．

離しの後の HNR は JVS と同じに戻る．b d は有声有気音ではない．

**有声摩擦**．こちらは有声有気音になっていた．声門が [h] 並みに開き，離しの後 40 ms 開いたまま（流量 500–720 cm³/s，母音は 350）．母音の頭の HNR は 8–14 dB（JVS 17–19）．開きを減らし，10 ms 早く戻して 16–17 dB．摩擦の中の声は −7〜−9 dB で，JVS（−14〜−27）より有声のまま．

**ら行**．約 9 ms 完全に閉じ，流量 0．面積は動きの 2 % で 0 → 0.15 cm² に飛ぶので，位置では半端な接触を作れない．TS3 が −0.2〜−0.35 で開く側面の流路（約 0.06 cm²）と，閉鎖とみなす面積 0.11 cm²（`contact_cm2`）で作った．1–8 kHz の落ち込みは −45 → −23 dB（JVS −23）．TS3 が 0.2 を超えると雑音源になる．

**早口**（`rate.py`，[rate-v111](results/rate-v111.json)，[rate-v112](results/rate-v112.json)）．話速 1 = 135 ms／モーラ．話速 0.5 の時の調音を 1 として，到達率の中央値．

## v1.1.4：b d g の前後の母音が大きすぎる

`world-decomposition/onset_peaks.py` で，b d g の後の母音の頭のピークが JVS より 6–7 dB 大きかった．話者は `build114.py`，測定は `onset_glottis.py`，`stop_scan.py`．

**原因**は `voiced-plosive` の声門そのものの大きさ．

- 同じスコアで b d g の声門だけを `modal` に替えると，ピークの中央値は 15.8 → 11.3 dB（前の母音 14.7 → 10.3）に下がる（`--swap`）．離しの形や口蓋帆ではない．τ を 3，15 ms にしてもほとんど変わらない．
- 定常の [a][e][o] で `modal` から `voiced-plosive` へ動かすと，ピークは単調に増え，端で +8.4，+5.6，+8.1 dB（`--steady`）．途中に山はない．**「移る途中で強くなる」という仮説は違った**．
- ピークの瞬間は，口腔内圧 0 %，口は開いたまま，声門は 9 割まで閉じている（11 トークンの中央値 0.89）．声門は閉鎖の 70 ms 前に閉じ始め，離しの約 40 ms 後まで戻らないので，その間は口の開いた母音を大きな声で鳴らしていた．大きさは，漏れの多いモーダルとの差から来る．

**直したのは話者だけ**：`voiced-plosive` の相対振幅 1 → 0.4，x 0.025/0.055 → 0.018/0.030．定常の母音でモーダルと同じ大きさ（a +0.1，e −3.7，o +1.1 dB）になる．振幅だけを下げると破裂の 2 kHz 以上が弱くなる（−14 → −25 dB）ので，その分を閉じ方で戻した．時間を縮める案（始め −45 ms，終わり −20 ms など）は，後の最大が 17 dB までしか下がらず，前の母音も残ったので使わない．規則は v1.1.3 のまま．

**WORLD の統計**（[stats-v1-1-4](../world-decomposition/results/stats-v1-1-4.json)）．無音を除く 27 量の平均 |z| は，ルール 1.78 → 1.50 → **1.91**，写し 1.10 → 1.13 → **1.21**（v1.1.0 → v1.1.3 → v1.1.4）と悪くなる．上がったのは，雑音/調波比の時間変動（3 kHz の SD 4.5 → 5.3 → 4.6 dB，JVS 6.5．6 kHz も同じ），音量の SD（6.3 → 6.4 → 5.7，JVS 6.7），ルールの F0 変動など，**変動の大きさ**で，ほとんどが v1.1.0 の値に戻った．b d g の前後の大きく澄んだ声が，v1.1.3 の変動を見かけの上で増やしていたと考えられる（量ごとの寄与は分けていない）．3 kHz の雑音/調波比の平均も −5.2 → −4.7 dB に戻る（JVS −9.6）．残るのはモーダルの息っぽさと変動の少なさで，子音の外の問題である．

**モーダルとの差に依存する**：0.4 は「v1.1.4 のモーダルと同じ大きさになる」ように選んだ絶対値．TBCM への切り替えやモーダルの変更の後は，`onset_glottis.py --steady` で差を見て，`stop_scan.py` で選び直す．

**t の規則**（v1.1.4 の話者と組）．試聴で濁音は良し，「t が強い」．k と t を一つの類で見ていたので隠れていた：t だけを見ると，破裂の 2–4 kHz が JVS より 10 dB 前後，4–8 kHz が 10–18 dB 強い（k はおおむね合う）．離したあとの気息が原因．

- 雑音源を一つずつ切った（`TdsModel.cpp` を書き換えた診断用ライブラリ）：気息を切ると 1–8 kHz が 12–34 dB 落ちる．**舌の雑音（破裂の本体）を切ってもほとんど変わらない**．t の音はほぼ全部が気息で，舌の破裂は人よりかなり弱い．舌の離しの τ，歯の隙間，TS3 が効かないのはこのため．
- `tt-alveolar-closure` は d n つ と共有，声門の形 `voiceless-plosive` は k p と共有（ら行は `tt-tap-*` で無関係）．t だけに効くのは時間のラベル．`glottis_begin_s`，`glottis_end_s`，`glottis_tau_s` が無声破裂にも効くようにした（ラベルのない区間は変わらない．.ges の一致で確認）．
- t の声門のジェスチャの終わりを，離しの 25 → 40 → 55 ms 前にした（`accent.TIMING["t"]`）．40 ms では「まだ強い」．60 ms でも変わらない（声門が離しの時にはモーダルに戻っている）．

閉鎖長と閉鎖中の声（−34〜−65 dB，JVS −40〜−48）は変わらず，清音のまま．早口は 1.5 倍以上で 40 ms と変わらない（声門の動作の下限 20 ms）．1–2 kHz は JVS より 5–12 dB 弱くなる．気息を減らした分，舌の破裂が足りないのが残る．「ち」「ちゅ」の破裂は触っていない．JVS は計算し直していない（前の測定値を使った）．WORLD の統計と `compare`，`rate` の再計算もしていない．試聴は [results/listen114t.html](results/listen114t.html)（25，40，55 ms の三つ）．

`world-decomposition` の v1.1.0 の値（10.6／9.9）は当時の backend と規則のもの．新しい規則で合成し直すと 6.7／6.9 になる．

