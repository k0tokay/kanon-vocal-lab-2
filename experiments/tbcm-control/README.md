# TBCM の制御：定常の「あー」と発話の違い

問題：ある F0 の「あー」ではうまくいって聞こえる TBCM(v1.4.1)が，発話では微妙に聞こえる．発話の中で何が定常母音と違うのかを測り，原因の候補を一つずつ切り替えて確かめた．そのうえで，筋活動の上に置く制御の層を設計し，効いた変更を最小限で試作した．聴取による採否は未定(候補を [試聴](results/listen.html) に並べた)．

## 結論

1. **母音の中ほどは，F0 が同じなら文でも定常でもほぼ同じ音**．母音または休止の後の母音では，H1−H2 の差 0.4 dB，閉鎖率の差 .002，2–5 kHz の落ちの差 0.4 dB．F0 が動くこと自体も効いていない(F0 を平らにしても差は変わらない)．
2. **発話で一番大きく系統的に違うのは，F0 とともに声が変わること**．肺圧が一定なので，F0 が高いほど弱く細くなる．3 文の母音では F0 1 半音あたり −0.87 dB(相関 −.74)で，アクセントの山が谷より約 8 dB 弱い．閉鎖率も 1 半音あたり −0.6 ポイント，2–5 kHz の落ちは +1.3 dB 変わる．定常の「あー」は 1 つの F0 で聴いて調整したので，この変化は聴こえていなかった(仮説 b・c)．
3. **無声子音の後の母音は暗く，漏れる**．中ほどで 2–5 kHz が 4.7 dB，前半で 7.9 dB 余分に落ち，閉鎖率が .04–.07 下がる．原因は**外転の名残り**(声門が母音の中でまだ閉じ切っていない)で，子音の声門形状の TA(声区)ではない(仮説 a は形を変えて成り立つ)．
4. 有声子音の後では TA・IA が母音の中ほどでも modal に届いていない(TA .42，IA .65)．ただし音の差は小さい(落ちで 1 dB)．
5. 姿勢の速さ(12)とジェスチャの時定数(10 ms)は今の値がよい(仮説 d は否定)．

試作の候補は3つ：(a) 子音の声門形状を modal の声区にそろえ，開きは元の形状に合わせる(話者ファイルだけ)，(e) 無声子音の後，開きを 15 ms 長く保ってから速く閉じる，(c) 肺圧を F0 に比例させる((e)(c) はスコアだけ)．

- (a)＋(e)：無声子音の後の余分な落ち(中 / 前半)が 4.7 / 7.9 → 1.6 / 2.0 dB．VOT は 17.6 → 16.6 ms でほぼ保たれ，子音の |z| は 1.28 → 1.25．
- (c)：レベルの F0 依存が −0.87 → 0.00 dB/半音．ただし子音の |z| は 1.34 に悪くなる(低い F0 の位置の摩擦音が弱まる)．
- 全部：落ち 2.3 / 2.7 dB，F0 依存 +0.01 dB/半音，子音 |z| 1.32，VOT 14.6 ms．

## 測り方

- [ges_probe.cpp](ges_probe.cpp)：ジェスチャスコアを `vtlGesturalScoreToAudio` と同じ手順で合成し，サンプルごとに声門の状態(声門流，制御パラメタ，歪み，声帯突起の位置，後部の開口，接触面積，測った F0 など 17 列)を書き出す．
- [diag.py](diag.py)：3 文(「今日はいい天気ですね」「雨が降っていますが…」「私の名前は嘉音です…」)を `accent.render`(規則 `timing = ja`，F0 は藤崎の規則)で作り，有声の母音 40 個を取り出す．それぞれに，**同じ母音を同じ目標 F0 で 0.9 秒伸ばした定常母音**を合成して対にする．どちらも母音の真ん中半分(定常側は同じ長さの窓)で測る．
- 測るもの：H1−H2 と 2–5 kHz の落ち(どちらも声門流の微分．落ちは H1 付近のエネルギーと 2–5 kHz のエネルギーの比)，閉鎖率(流れが最小＋振幅の 10 % を下回る割合)，漏れ(流れの最小値)，F0 誤差(流れの周期と目標の差)，有声の立ち上がり(流れの交流振幅が母音の中ほどの半分に達する時刻)．
- 前の版の測り方で 2–5 kHz の落ちを帯域の平均で取っていたところ，窓の長さで 9 dB 変わる誤りがあったので，エネルギーの和に直した．
- 無声化した母音(流れの最小が 50 cm³/s を超えるもの)は除いた．

### (a) 子音の声門形状の TA

子音の形状(`make_speaker.py` の初期値)は TA .15–.20，CT .20 で，modal(TA .455，CT .522)と大きく違い，筋活動の空間で線形に補間されるので，子音のたびに TA が 60 ms ほどかけて .15 から .455 へ戻る([図](results/course-tenki.png) の左)．

- TA と CT を modal にそろえるだけで，無声子音の後の差はほぼ消える．ただしこれは**声区の効果ではない**．TA を上げると F0 制御の選ぶ歪みが変わり，後部の開口が変わるので，同じ LCA・IA でも無声の形状の開きが半分になる(声帯突起の位置 1.13 → .51 mm，後部の開口 4.2 → 3.3 mm²)．その分 VOT が 18 → 11 ms に縮み，有声摩擦の摩擦が 5–6 kHz で 15 dB 弱まって，子音の |z| が 1.28 → 1.41 に悪くなる．
- TA・CT を modal にし，LCA・IA・PCA を解き直して**開きを元の形状と同じ**にすると([invert.py](invert.py))，母音の差は元に戻る(+5.0 / +8.3 dB)．子音は少し良くなる(1.22．有声摩擦・破擦と ts)．
- つまり，無声子音の後の母音を暗くしているのは外転の名残りで，TA の揺れそのものは母音の測定値にほとんど出ない．有声子音の後でも TA を modal にそろえて変わるのは落ちで 0.3 dB 以下．

### (e) 閉じを速くする

無声子音の直後の声門ジェスチャ(modal)の時定数だけを 10 → 6 ms にすると，外転の大きさは変えずに母音の始めで声門が閉じる．無声子音の後の余分な落ちは 5.0 / 8.3 → 1.6 / 1.4 dB．ただし気音も短くなり，VOT が 16.3 → 11.5 ms(JVS は 23.8 ms)に縮む．子音の |z| の平均が 1.22 のままなのは，s・ɕ が良くなった分と打ち消し合っているため．

そこで閉じ始め(直後のジェスチャの始まり)を遅らせ，開いている時間を保ってから速く閉じるようにした．15 ms 遅らせると VOT 16.6 ms(元 17.6)，無声子音の後の余分な落ちは 1.6 / 2.0 dB，子音の |z| は 1.25．時定数を全部 5 ms にすると F0 の誤差が 0.39 半音に増え，H1−H2 が 2 dB ずれるので，直後だけにした．

### (b)(c) F0 と圧

F0 制御は CT を使わず，目標の F0 になる歪みを二分法で決める．TA と圧は一定なので，F0 を上げると声帯は伸びて薄くなり，流れの振幅が減る．F0 を 1 文の中で一定にしても文と定常の差は変わらないので，F0 が**動く**ことは問題ではなく，F0 の**値**ごとに声が違うことが問題になる．

圧を F0 に比例させると(165 Hz で 6000，310 Hz で 11300 dPa)，母音のレベルの F0 依存がなくなり，閉鎖率と落ちの F0 依存が半分以下になる．F0² に比例させるとレベルが F0 とともに上がる(+0.96 dB/半音)．ただし圧は子音にも効くので，低い F0 の位置の摩擦音の高域が弱まり，子音の |z| が 1.28 → 1.34 に悪くなる(ɕ，tɕ，z の 6 kHz)．(a)(e) と合わせても 1.32．子音の間は圧を F0 に追従させない(または句の単位で滑らかにした F0 に追従させる)のが次の候補．

### (d) 速さと時定数

姿勢の速さ 20 は 12 と同じ．4 にすると漏れが倍になる．声門ジェスチャの時定数は 5 ms で F0 誤差が増え，20 ms で漏れと閉鎖率の差が大きくなる．今の値(12，10 ms)でよい．

### 残る問題

- 句末の下降で F0 が 0.5–0.7 半音高いまま残る母音がある(F0 制御の補正が 1 周期ごとの積分なので，下降に遅れると考えられる．未確認)．無声子音の直後も高めに外れる(+0.25 半音)．今回は直していない．
- 測っているのは母音の音だけ．無声子音の後の息っぽい始まりは実際の発話にもあるので，どこまで閉じを速くするのが自然かは聴いて決める必要がある．JVS の母音の始まりと比べる手もある(未着手)．

## 制御の層の設計案

今の下層は，筋活動 5 つ(LCA，IA，PCA，CT，TA)，肺圧，F0(F0 制御の目標)，flutter．modal などの声門形状は，この下層の点として話者ファイルに書かれ，ジェスチャごとに筋活動の空間で補間される．診断から分かったのは，**筋活動の空間での補間は，聴こえの上で意味のある量(声区，閉じ方，開き，強さ)を独立に保たない**ことだった．TA を変えると開きも変わり，F0 を変えると声区と強さも変わる．

### 上の層の座標

| 座標 | 意味 | 下層への主な写像 | 子音で変えるか |
|---|---|---|---|
| F0 | 高さ | F0 制御の歪み(今のまま) | 変えない |
| 声区 r | 0 地声 … 1 裏声 | TA(F0 制御なしなら CT との比も) | 変えない |
| 内転 q | 閉じ方．声帯突起の位置 VP と後部の開口 PGO | LCA，IA(F0・TA ごとに解く) | 有声子音でわずかに |
| 外転 u | 無声化のための開き(VP，PGO を大きくする) | LCA，IA，PCA | 無声子音で 1 |
| 努力 e | 強さ．基準の圧に対する倍率 | 肺圧 = p₀ · e · (F0 / F0₀)^k | 変えない |
| 気息 | 雑音の強さ(静的) | `aspiration_strength` | — |

- **modal などの形状は，この空間の点**：modal = (r = r_modal，VP .11 mm，PGO .30 mm²，e = 1)．breathy は VP・PGO を大きく，pressed は小さく e を上げ，falsetto は r を 1 に，chest は r を 0 に寄せる．
- **子音は外転と内転だけを変える**．声区と努力は母音のものを保つ．今の話者では，子音の形状が r(TA) も持っていたため，形状を変えるたびに声区が揺れていた．
- **地声・裏声は r の 1 軸**．歌では r を F0 の関数(換声点)として与えられる．発話では r は一定でよい．
- **F0 と努力の結合**：F0 を変えても声の性質(閉鎖率，H1−H2，振幅)が保たれるように圧を F0 とともに動かす．k = 1 で振幅が一定，k = 2 でレベルが F0 とともに上がる．発話で自然な k は聴いて決める．

### 上から下への写像

- **内転・外転 → LCA・IA・PCA**：[posture_map.cpp](posture_map.cpp) が筋活動から VP・PGO を音なしで計算する(1 形状を解くのに数百回呼んで 1 秒以下)．[invert.py](invert.py) は，与えた TA・CT・F0 で目標の VP・PGO になる LCA・IA・PCA を解く(元の値と PCA 0 への弱い引き戻しつき)．F0・TA の格子で解いておけば表になる．`smooth.py` で示したとおり，F0 制御の下では LCA・IA・PCA は VP と PGO を通してしか音に効かないので，この 2 次元で十分．
- **声区 → TA**：F0 制御の下では直接 TA．F0 制御なし(CT が F0 に効く)では，`natural.py` のヤコビアンと掃引から (F0，r) → (CT，TA) の表を作る．
- **努力・F0 → 圧**：上の式．

### 時間の扱い

上の層の座標をジェスチャ(目標値＋時定数)で動かし，サンプルごと(または姿勢の更新ごと)に下層へ写像する．補間は上の層で行われるので，子音で u が 0 → 1 → 0 と動いても r と e は動かない．今回の試作は，この写像を**話者ファイルの形状とスコアの編集で近似**したもの：

1. 子音の形状に modal の TA・CT・flutter を入れ，LCA・IA・PCA を元の開きに合わせて解く(話者ファイル)．補間は筋活動の空間のままだが，TA・CT は動かなくなり，開きは元と同じになる．
2. 無声子音の直後のジェスチャを 15 ms 遅らせ，時定数を短くする(スコア)．
3. 肺圧を F0 に追従させる(スコア，20 ms ごとの段)．

最終的には BodyCoverGlottis の制御パラメタを上の層(F0，r，q，u，e)にし，形状もその値で持つのがよい．GUI と話者ファイルの形式が変わるので，今回はしていない．

## 試聴

[results/listen.html](results/listen.html)(音声は埋め込み，合成のみ)．

- 定常の母音を 165 → 205 → 255 → 310 Hz と続けたもの：圧一定と圧 ∝ F0．全体で音量をそろえたので，F0 ごとの音量差は残っている．
- 3 文 × 6 版：そのまま，(a) 開きを合わせた版，(a)＋(e) 15 ms，(c)，(a)＋(e)＋(c)，参考に TA・CT だけそろえた版．文ごとに音量をそろえた．

聴く点：アクセントの山と句末の低いところで声の太さ・強さが変わるか(c)，「て」「た」「と」の後の母音の始まりの暗さ・息(e)．(a) 単独は母音の測定値をほとんど変えないので，違いは聴こえないかもしれない．

## 限界

- 3 文，母音 40 個(無声子音の後は 6 個)．F0 は藤崎の規則で，学習 F0 ではない．
- 「定常母音と同じ」を目標にしたが，実際の発話の母音が定常母音と同じ声とは限らない．特に無声子音の後の息っぽさと，F0 とレベルの関係の強さ(k)は，聴取か録音で決める必要がある．
- 開きを合わせたのは 220 Hz，8000 dPa の静的な姿勢．振動中や他の F0 では少しずれる．
- 子音の検査は 1 回の合成(5 文)．|z| の 0.03 程度の差は意味がない．
- 圧の追従は 20 ms ごとの段で，時定数 20 ms．子音の圧も F0 とともに変わる．
