# 声道を大きくしてフォルマントを下げる（調音はそのまま）

v1.3.1 の声道（/a/ で 11.9 cm）を 1.08〜1.25 倍にし，フォルマントを下げた．声門と規則は v1.3.1 のまま．
**1.14 倍を採用し，v1.4.0（`speakers/fulkhisa-kanon/fulkhisa-kanon-v1-4-0.speaker`）とした．** ほかの候補は `fulkhisa-kanon-v1-3-1-tract-{1-08,1-2,1-25}.speaker`，試聴は [results/listen.html](results/listen.html)（合成音だけ）．

## 方法

1. **相似拡大**（`scale.py`）．解剖と，長さの調音パラメタ（目標と可動域）をすべて k 倍する．角度と無次元のパラメタは変えない．閉鎖は閉鎖のまま，狭めの相対的な位置も変わらない．変えないもの：TS1〜3（VTL の絶対値のしきい値で読まれる），VO，梨状窩・鼻腔・気管（もともと成人大），声門．
2. **狭めの余裕を戻す**（`build.py`）．面積は k² で広がるのに，摩擦のしきい値（0.17 cm²）などは絶対値なので，母音へ戻り始めてすぐ狭めが開く形が出る．元の余裕（v1.3.1 と `consonant-articulation/build.py` の目標の小さいほう）を 0.03 より割った形だけ，同じ位置・同じ余裕になる所まで舌を最小限動かした．動かしたのは ɕ(i)，ç(i)，k(i)，k(u) の四つで，最大 1.2 mm（k = 1.14 では 0.7 mm）．ɸ の唇は 0.12 cm² に戻し，ら行の横の隙間は k² 倍にした．k ≥ 1.2 で t(i)，後部歯茎閉鎖(i) の余裕が 0.03〜0.04 下がったまま（直す形が見つからない）．

以前の [anatomy-compensation](../anatomy-compensation/README.md) と違い，フォルマントは保たず，13 個の解剖パラメタも使わない．`AnatomyParams::setFor` は歯列の長さなどを伸縮しないので，13 個を k 倍しても相似にならない．

- **形**（shapelib，k = 1.14）：閉鎖はすべて閉じたまま，狭めの位置の相対差は 0.02 以内．例外は tt-alveolar-fricative(i) と alveolopalatal(i) で，0.86 → 0.90，0.80 → 0.84（一続きの狭めの中での最小点の移動．狭めの後ろの端が開いて短くなる）．F15 は ɕ(i)・ç(i) の狭めがなくなり（余裕 0），後部歯茎閉鎖(i) は閉じなくなる．w j も大きく崩れる．
- **到達率**（`rate.py`，1，1.5，2 倍速）：どの k でも v1.3.1 と 0.02 以内．ç ɸ だけ 1 倍速で 1.03 → 1.00．
- 閉鎖長（44 → 43 ms），閉鎖中の声（−22 → −20 dB），ら行の落ち込み（−26 → −26 dB，JVS −23）は変わらない（k = 1.14）．

**悪くなるもの**：

- tɕ：前腔の共鳴が下がり，重心 5.5 → 5.0（1.14），4.7 kHz（1.2）．JVS 5.5．強さも母音に対して 6 → 8，13 dB（JVS 7.5）．
- 鼻音の 1–2 kHz：−25 → −28，−30 dB（JVS −10．もとから弱い）．口蓋帆の開きを k² 倍にしても直らない（`rules_test.py`）．
- ɾ の 2–4 kHz：0 → −8 dB（JVS +1）．落ち込みの深さではなく F2・F3 が帯の外へ下がるためと思われるが，確かめていない．

**良くなるもの**：s の 6 kHz 以上（−15 → −5 dB，JVS −6），ɕ の重心（4.7 → 5.0 kHz，JVS 5.7），ɸ h ç の重心（3.6 → 2.6 kHz，JVS 2.1）．

規則の絶対値（口蓋帆の開き，弾きの接触面積，b d g の口蓋帆の漏れ）を k² 倍にする必要はなかった（平均 |z| の差 0.03 以内，1.14）．

## 手順

```sh
build.py 1.14                                  # → out/k1.14.speaker（--glottis=ほかの話者 でその声門を使う）
build.py 1.14 out/u1.14.speaker --no-polish    # 相似拡大だけ
f15.py                                         # 比較用
../consonant-articulation/compare.py k1.14=…   # 検査（結果は results/ に移した）
rules_test.py 1.14 r=out/k1.14.speaker v c l
listen.py
```

`JVS_NPZ`，`VTL_LIB` が要る（consonant-articulation の README）．
