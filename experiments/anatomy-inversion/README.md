# Sun 2022 の解剖・調音同時推定（EmJEm）を合成データで再現する

Sun, Huang & Wu (Interspeech 2022) の EmJEm を VTL 2.4 と嘉音の話者ファイルで再現した。正解の分かる合成話者で、音声から解剖パラメタ13個と調音軌跡がどこまで戻るかを調べた。

**注意：この合成話者は調音を補償していない。** VTL は解剖を変えると、音素の目標形状を単純な拡大縮小で調整するだけである（`adaptArticulation`）。そのため /e/ と /ɯ/ の区別が4分の1の話者で崩れ、/ʃ/ の狭めはほぼ全員で開き、i の文脈の閉鎖は半数前後で閉じない（[話者チェック](results/speaker-check.json)、[母音図](results/speaker-check.png)、[試聴](results/listening/phrase-all.wav)）。人間は解剖に合わせて調音を補償し、音を保つ。したがって以下の解剖の復元成績は、実際の話者に対しては楽観的な見積もりである。

## 結果（テスト話者8名）

| 条件 | 声道パラメタの相関 | 声門パラメタの相関 | log f0 の RMSE | ケプストラム距離 |
|---|---:|---:|---:|---:|
| oracle（正解で教師あり学習） | 0.93 | 0.74 | 0.076 | 4.87 dB |
| SP-AM（話者ごとに解剖を推定） | 0.33 | 0.43 | 0.108 | 4.74 dB |
| UT-AM（発話ごとに解剖を推定） | 0.30 | 0.36 | 0.104 | 4.63 dB |
| FIX-AM（嘉音に固定） | 0.12 | 0.27 | 0.128 | 5.52 dB |

相関は発話ごと・パラメタごとに求めて平均した。ケプストラム距離は、推定値で再合成した音声と元の音声の比較である。対数メルスペクトルの DCT から計算しており、SPTK の MCD とは値の尺度が違うので、条件間の比較にだけ使う。

- 解剖を推定すると、音の再現と調音の推定の両方が良くなる。解剖を固定すると、舌体（TCX/TCY）の相関は 0.84/0.77 から 0.41/0.16 に落ちる。論文が述べている補償の問題が再現した。
- 音はどの条件でもほぼ再現できるのに、調音の相関は 0.3 程度にとどまる。舌体と舌尖は合うが、舌背、舌根、舌骨は別解に落ちる。
- oracle の解剖は訓練話者56名を丸暗記しただけで、テスト話者では平均値を答えるより悪かった（RMSE 0.49、平均値なら 0.44）。解剖が56通りしかないためである。

## 解剖パラメタの復元

正解を一度も見ていない訓練話者56名で、話者ごとの推定値と正解の相関を求めた。

| パラメタ | SP-AM | UT-AM |
|---|---:|---:|
| 喉頭長 H1 | 0.94 | 0.96 |
| 咽頭長 H0 | 0.80 | 0.89 |
| 声帯長 W3 | 0.73 | 0.82 |
| 上奥歯の高さ H3 | 0.49 | 0.70 |
| 硬口蓋長 W1 | 0.66 | 0.70 |
| 喉頭幅 W4 | 0.57 | 0.68 |
| 口蓋の幅 D0 | 0.51 | 0.52 |
| 口蓋の高さ H2 | 0.39 | 0.45 |
| 口咽頭角 A0、下顎の高さ H5、軟口蓋長 W2 | ≤ 0.31 | ≤ 0.31 |
| 唇の幅 W0、下奥歯の高さ H4 | ≈ 0 | ≈ 0 |

相関は高くても値の尺度はずれており、全体の RMSE は平均値を答える場合より悪い。声道の長さを決めるパラメタは取れる。一方、口の中の細かい寸法は音から決まらない。UT-AM の発話ごとの推定値は、話者内で標準偏差 0.05〜0.14（正規化単位）ばらつく。

## 実装

- C API に4つの関数を追加した（`vtlGetAnatomyParamInfo`、`vtlSetAnatomyParams`、`vtlSynthesizeTrajectory`、`vtlGesturalScoreToParamFrames`）。解剖の値は常に話者ファイルの声道を基準に計算するので、同じ値を設定すれば必ず同じ結果になる。一括合成の出力は、フレームごとの従来 API とビット単位で一致する（`check_api.py`）。
- `AnatomyParams.cpp` が、VTL 2.4 で3個に減った舌側面パラメタを4個分書き込んでいた。このため声道の形状リストのメモリが壊れ、口蓋の幅を変えると落ちていた。これを修正した。
- `gen_dataset.py`：仮想話者64名、各80発話。解剖は各範囲の内側 80% から独立に一様に引き、発話は日本語風のランダムなモーラ列とした。
- `emjem.py`：設定は論文に揃えた（σ 0.5 を毎反復 0.98 倍、λ 0.1、Adam 5e-4）。論文との違いは次の4点。
  - フレームに加えるノイズは時間方向に平滑化した。
  - 調音は、その解剖に合わせて調整された可動域で正規化した。
  - 1反復あたり600発話を合成し、最新6000組をリプレイバッファに残して使った。
  - 解剖を推定する BLSTM は、順方向と逆方向の LSTM に分けて実装した。MPS では pack した系列が遅いためで、計算結果は同じである。
- 極端なパラメタでは VTL の時間領域シミュレーションの行列が正定値でなくなり、音声が NaN になる。その発話は捨てた（1反復あたり 0〜12%）。

再現手順：
```
python3 gen_dataset.py data/synth-v1
./run_all.sh 120
python3 check_speakers.py
python3 render_listening.py
```
