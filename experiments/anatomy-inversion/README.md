# Sun 2022 の解剖・調音同時推定（EmJEm）を合成データで再現する

Sun, Huang & Wu (Interspeech 2022) の EmJEm を VTL 2.4 と嘉音の話者ファイルで再現した。正解の分かる合成話者で、音声から解剖パラメタ13個と調音軌跡がどこまで戻るかを調べた。

**注意：この合成話者は調音を補償していない。** VTL は解剖を変えると、音素の目標形状を単純な拡大縮小で調整するだけである（`adaptArticulation`）。そのため /e/ と /ɯ/ の区別が4分の1の話者で崩れ、/ʃ/ の狭めはほぼ全員で開き、i の文脈の閉鎖は半数前後で閉じない（[話者チェック](results/speaker-check.json)、[母音図](results/speaker-check.png)、[試聴](results/listening/phrase-all.wav)）。人間は解剖に合わせて調音を補償し、音を保つ。したがって以下の解剖の復元成績は、実際の話者に対しては楽観的な見積もりである。

## 結果（テスト話者8名）

| 条件 | 声道パラメタの相関 | 声門パラメタの相関 | log f0 の RMSE | ケプストラム距離 |
|---|---:|---:|---:|---:|
| oracle（正解で教師あり学習） | 0.93 | 0.74 | 0.076 | 4.87 dB |
| SP-AM（話者ごとに解剖を推定） | 0.33 | 0.43 | 0.108 | 4.74 dB |
| UT-AM（発話ごとに解剖を推定） | 0.30 | 0.36 | 0.104 | 4.63 dB |
| FIX-AM（嘉音に固定） | 0.12 | 0.27 | 0.128 | 5.52 dB |

相関は発話ごと・パラメタごとに求めて平均した。ケプストラム距離は、推定値で再合成した音声と元の音声の比較である。対数メルスペクトルの DCT から計算しており、SPTK の MCD とは値の尺度が違うので、条件間の比較にだけ使う。

- 解剖を推定すると、音の再現と調音の推定の両方が良くなる。解剖を固定すると、舌体（TCX/TCY）の相関は 0.84/0.77 から 0.41/0.16 に落ちる。論文が述べている補償の問題が再現した。
- 音はどの条件でもほぼ再現できるのに、調音の相関は 0.3 程度にとどまる。舌体と舌尖は合うが、舌背、舌根、舌骨は別解に落ちる。
- oracle の解剖は訓練話者56名を丸暗記しただけで、テスト話者では平均値を答えるより悪かった（RMSE 0.49、平均値なら 0.44）。解剖が56通りしかないためである。

## 解剖パラメタの復元

正解を一度も見ていない訓練話者56名で、話者ごとの推定値と正解の相関を求めた。

| パラメタ | SP-AM | UT-AM |
|---|---:|---:|
| 喉頭長 H1 | 0.94 | 0.96 |
| 咽頭長 H0 | 0.80 | 0.89 |
| 声帯長 W3 | 0.73 | 0.82 |
| 上奥歯の高さ H3 | 0.49 | 0.70 |
| 硬口蓋長 W1 | 0.66 | 0.70 |
| 喉頭幅 W4 | 0.57 | 0.68 |
| 口蓋の幅 D0 | 0.51 | 0.52 |
| 口蓋の高さ H2 | 0.39 | 0.45 |
| 口咽頭角 A0、下顎の高さ H5、軟口蓋長 W2 | ≤ 0.31 | ≤ 0.31 |
| 唇の幅 W0、下奥歯の高さ H4 | ≈ 0 | ≈ 0 |

相関は高くても値の尺度はずれており、全体の RMSE は平均値を答える場合より悪い。声道の長さを決めるパラメタは取れる。一方、口の中の細かい寸法は音から決まらない。UT-AM の発話ごとの推定値は、話者内で標準偏差 0.05〜0.14（正規化単位）ばらつく。

## 実音声（JVS 100話者）

JVS の parallel100 と nonpara30（100話者、12,997発話）で SP-AM と FIX-AM を120反復学習した。正解がないので、話者タグ（性別、f0 の範囲）との関係と再合成の音で評価した（[SP-AM](results/jvs-sp/eval.json)、[FIX-AM](results/jvs-fix/eval.json)、[話者ごとの推定値](results/jvs-sp/speakers.csv)）。

| | SP-AM | FIX-AM |
|---|---:|---:|
| ケプストラム距離（208発話） | 7.79 dB | 8.00 dB |
| 推定 f0 とタグ f0 の相関（話者単位、対数） | 0.97 | 0.96 |
| /a/ の声道長　女性 / 男性 | 13.48 / 13.65 cm | 12.05 cm（嘉音） |

- 解剖は話者ごとに安定して推定される。話者ごとの差が大きいパラメタ（H2、D0、H1、W4、A0）では、話者内のばらつきは話者間のばらつきの3分の1程度である。
- しかし、物理的にもっともらしい解剖にはなっていない。/a/ の声道長は男女差が 0.17 cm（約1%）しかない。全員が 13.1〜14.2 cm に収まり、実際の男女差（15〜20%）にはほど遠い。
- 男女差がはっきり出るのは、喉頭長 H1、口蓋の幅 D0、口咽頭角 A0、咽頭長 H0 である（|d| ≈ 1.7〜2.0）。これらはタグ f0 とも相関する（|r| 0.6〜0.7）。ただし咽頭長は女性のほうが長く出ており、向きが逆である。解剖の推定は声道の大きさではなく、f0 や声質と結びついた手がかりを拾っている疑いがある。
- 解剖を推定しても、再合成の改善は 0.2 dB にとどまる（合成話者では 0.8 dB）。距離そのものも合成話者（4.7 dB）よりずっと大きい。VTL の音と実音声の差が、解剖の差より大きい。
- 合成した発話のうち、σ が大きい序盤は最大で半分近くが NaN か振幅超過で捨てられた。終盤も振幅超過が1反復あたり15%前後残った。実音声では合成音を音量で正規化するので、振幅超過で捨てる必要はない。大きな声の推定値が学習から外れるため、この扱いは次の実行で直すべきである。

### 基準の声道を JD2 に替えた場合

嘉音の声道は短く（/a/ で 12.05 cm）、喉頭まわりのパラメタが範囲の端に近い。この影響を見るため、声道を JD2（15.62 cm）に替えて同じ条件で学習した。声門モデルは嘉音のまま（JD2 の声門 2019 は f0 が 160 Hz を超えると NaN になる）。結果は [SP-AM](results/jvs-jd2-sp/eval.json)、[FIX-AM](results/jvs-jd2-fix/eval.json)、[話者ごとの推定値](results/jvs-jd2-sp/speakers.csv)。

| | 嘉音 SP-AM | 嘉音 FIX-AM | JD2 SP-AM | JD2 FIX-AM |
|---|---:|---:|---:|---:|
| ケプストラム距離 | 7.79 dB | 8.00 dB | 7.68 dB | **7.43 dB** |
| （評価できた発話数） | 208 | 208 | 206 | 207 |
| 推定 f0 とタグ f0 の相関 | 0.97 | 0.96 | 0.96 | 0.97 |
| /a/ の声道長　女性 / 男性 | 13.48 / 13.65 cm | 12.05 cm | 12.56 / 13.59 cm | 15.62 cm |

| 男女差（Cohen の d、女性−男性） | H0 | H1 | W3 | A0 | D0 | H3 |
|---|---:|---:|---:|---:|---:|---:|
| 嘉音 SP-AM | 1.76 | -1.97 | 0.62 | 1.78 | -1.73 | -1.65 |
| JD2 SP-AM | -3.03 | -2.26 | -2.08 | 0.32 | -1.01 | -0.83 |

- 基準を替えると H0 と W3 の男女差の符号が逆転した。解剖の推定は基準の話者に強く依存すると見られる。JD2 では向きが実際と合い、/a/ の声道長の男女差も 0.17 cm から 1.03 cm（約8%）に広がったが、これだけで解剖を復元できたとは言えない。
- JD2 では解剖を固定したほうが 0.25 dB 良く、嘉音（推定したほうが 0.2 dB 良い）と逆になった。解剖の推定が再合成を良くするという証拠はない。
- 推定された声道長は全話者で JD2 より短い（11.5〜14.0 cm）。
- JD2 の SP-AM では、性別の中で見ると H0・H1・W3 とタグ f0 の相関は弱い（|r| ≤ 0.25）。差は話者の大きさではなく、性別と結びついた別の手がかりによる可能性も残る。
- 限界：各条件とも学習は1回だけで、乱数による変動は測っていない。嘉音の2条件は振幅超過の発話を捨てていた（JD2 は捨てない）ので、嘉音と JD2 の差には声道以外の違いも含まれる。JD2 の SP-AM では序盤に最大 60%（200 発話中 121）、FIX-AM でも最大 48%（95）が NaN で捨てられた。最後の20反復は 0〜7。

再現手順（JVS は再配布できないので各自で入手する。音声を含む出力は `data/` に置き、リポジトリには入れない）：
```
MODES="sp fix" PER_ITERATION=200 ./run_jvs.sh JVS_ROOT data/jvs-v1 data/runs-jvs
```
Colab では `colab_jvs.ipynb` が同じスクリプトを実行する。ただし操作のない状態が続くとランタイムが切断されるので、長時間の実行には向かない。

## 実装

- C API に4つの関数を追加した（`vtlGetAnatomyParamInfo`、`vtlSetAnatomyParams`、`vtlSynthesizeTrajectory`、`vtlGesturalScoreToParamFrames`）。解剖の値は常に話者ファイルの声道を基準に計算するので、同じ値を設定すれば必ず同じ結果になる。一括合成の出力は、フレームごとの従来 API とビット単位で一致する（`check_api.py`）。
- `AnatomyParams.cpp` が、VTL 2.4 で3個に減った舌側面パラメタを4個分書き込んでいた。このため声道の形状リストのメモリが壊れ、口蓋の幅を変えると落ちていた。これを修正した。
- `gen_dataset.py`：仮想話者64名、各80発話。解剖は各範囲の内側 80% から独立に一様に引き、発話は日本語風のランダムなモーラ列とした。
- `emjem.py`：設定は論文に揃えた（σ 0.5 を毎反復 0.98 倍、λ 0.1、Adam 5e-4）。論文との違いは次の4点。
  - フレームに加えるノイズは時間方向に平滑化した。
  - 調音は、その解剖に合わせて調整された可動域で正規化した。
  - 1反復あたり600発話を合成し、最新6000組をリプレイバッファに残して使った。
  - 解剖を推定する BLSTM は、順方向と逆方向の LSTM に分けて実装した。MPS では pack した系列が遅いためで、計算結果は同じである。
- 極端なパラメタでは VTL の時間領域シミュレーションの行列が正定値でなくなり、音声が NaN になる。その発話は捨てた（1反復あたり 0〜12%）。

再現手順：
```
python3 gen_dataset.py data/synth-v1
./run_all.sh 120
python3 check_speakers.py
python3 render_listening.py
```
